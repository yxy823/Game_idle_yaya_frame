# 框架出现可复现问题，需要修复

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

框架出现可复现问题，需要修复。需要的材料：

- **问题与证据：** 复现步骤、期望与实际行为、日志。
- **验证边界：** 获准验证范围。

## 前置条件与适用范围

实际框架行为偏离现有契约，目标是修复已定位的问题。

## 执行步骤

使用[集中提示词库](<../../../prompts/yaya-maintenance-prompts.json>)中的“Yaya 框架维护 → 维护与复盘 → 框架出现可复现问题，需要修复”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页由当前 Agent 使用现有规则和工具处理；需要独立审核的步骤明确交给独立实例。

**S1｜建立复现依据**

当前 Agent 读取报错及实际调用链，区分工具缺陷、说明失效与运行环境问题。原因尚不明确时，用原症状对应的复现和证据区分候选原因，复用已有结果后继续本次修复，不增加独立阶段。

**S2｜修复根因**

在维护源局部修正，同步直接调用者与回归用例，不放宽既有验收规则。

**S3｜复核修复**

按授权检查原触发路径及相邻失败行为，报告失败与未执行项后本地提交。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 缺陷及触发条件明确 |
| S2 | 根因及必要关联已修正 |
| S3 | 原问题证据与修复结果可比较 |

## 资源与文件影响

相关源文件、必要回归和说明修改；已有游戏不自动更新。

## 阻塞、异常与范围变化

无法复现时保留静态推断与待运行项，不能称故障已消失。

## 完成状态与验证标准

原问题有对应修复与适用验证；影响范围、剩余限制和提交明确。
