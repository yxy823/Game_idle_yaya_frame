# 框架任务还没做完，准备换一个对话继续

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

框架任务还没做完，准备换一个对话继续。需要的材料：

- **任务目标与范围：** 原目标、当前范围。
- **续接依据：** 已有决定和下一步。

## 前置条件与适用范围

需要把同一维护仓库的未完成工作交给新对话。

## 执行步骤

使用[集中提示词库](<../../../prompts/yaya-maintenance-prompts.json>)中的“Yaya 框架维护 → 维护与复盘 → 框架任务还没做完，准备换一个对话继续”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页由当前 Agent 使用现有规则和工具处理；需要独立审核的步骤明确交给独立实例。

**S1｜核实真实停点**

当前 Agent 只读根规则、framework/progress.md、当前差异及必要报告，核对有效授权，区分已实施、仅建议与失败；本次不授权更新停点文件。

**S2｜生成可复制交接**

写明实际目录、提交、关键路径、下一步和检查限制；未取得的批准或验收保留缺口。

## 资源与文件影响

仓库与原始记录只读；输出一个完整交接文本，不创建 Handoff 文件或自动新建任务。

## 阻塞、异常与范围变化

未知事实明确标注；不清空工作区或为交接制造提交。

## 完成状态与验证标准

交接文本可直接复制，包含真实停点、有效授权、证据与下一步。

## 流程关联与衔接关系

依据：[维护约定](<../../../../../AGENTS.md>)、[职责设计准则](<../../../../docs/framework-maintenance/baselines/skill-script-prompt-design.md>)。本页完成后暂停原任务的实施，保留原有具体授权和真实现场；收到用户续接指令后，再从记录的停点恢复。不得因先前存在实施授权而立即继续已被要求暂停的工作。
