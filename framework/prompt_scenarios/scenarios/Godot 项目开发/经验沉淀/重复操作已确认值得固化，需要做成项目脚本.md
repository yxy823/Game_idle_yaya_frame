## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 经验沉淀 → 重复操作已确认值得固化，需要做成项目脚本”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页使用 [$engineering-change-plan](<../../../../../project-source/skills/engineering-change-plan/SKILL.md>)、[$feature-execute](<../../../../../project-source/skills/feature-execute/SKILL.md>)，具体执行者和切换位置见下文。

**S1｜确定工具契约**

当前 Agent 比较复用现有命令、合并和最小新增工具，明确操作目标、副作用、失败和清理。

**S2｜完成工程实现**

按 maintenance 任务由 feature-execute 固化最小实现，去除一次性绝对路径，复用已有基础函数。

**S3｜验证并说明用法**

覆盖实际输入、输出及失败保护，补最少使用说明和知识链接，按所属任务交付。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |

| S3 | 脚本有相称验证而非只保存代码 |
