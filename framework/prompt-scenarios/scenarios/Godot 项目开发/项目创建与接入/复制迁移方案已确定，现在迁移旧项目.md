# 复制迁移方案已确定，现在迁移旧项目

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

复制迁移方案已确定，现在迁移旧项目。需要的材料：

- **来源与目标**：原项目和框架路径、独立空目标。
- **迁移决定**：已选方案、历史与样本数据选择。
- **运行授权**：获准运行范围。

## 前置条件与适用范围

原件只读，复制及验证只在独立目标内，方案已经明确。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 项目创建与接入 → 复制迁移方案已确定，现在迁移旧项目”。填入上述材料。

**S1｜检查目标隔离**

当前 Agent 核对以下隔离条件：

- **目标路径**：不存在或为空、无中文空白且与两输入互不包含。
- **链接与 Git 指针**：不会写回原件。

**S2｜保留成果并转换**

按已选方案复制实际成果和必要定制，转换当前工具所需结构；保留 Feature ID、AC、真实完成历史和有效引用。

**S3｜验证目标并交接**

按获准范围检查环境、台账和业务；真实数据只用获准副本。记录原项目未变核对与续接点并提交目标。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 目标写入及运行不会触及原项目 |
| S2 | 目标可读取原有成果且无伪造历史 |
| S3 | 迁移报告和真实验证可追查 |

## 资源与文件影响

只写目标；保存 reports/maintenance/framework-migration/migration.md 与必要 Progress。原件不删除、不执行测试。

## 阻塞、异常与范围变化

无法无损表示的历史、隔离失败或缺失验收如实保留，不能改检查器或放宽 AC 放行。

## 完成状态与验证标准

独立目标保留有效成果，必要转换与验证完成；报告、提交和原业务待办明确。
