# 工具位置或版本变了，需要更新项目环境

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

工具位置或版本变了，需要更新项目环境。需要的材料：

- **工具变化**：改变的工具、新路径或版本。

## 前置条件与适用范围

已有有效初始化记录，本次只调整指定环境项。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 项目创建与接入 → 工具位置或版本变了，需要更新项目环境”。填入上述材料。本页由当前 Agent 使用项目自己的 `project-environment-godot` Skill；[源码入口](<../../../../../project-source/skills/project-environment-godot/SKILL.md>)仅供核对。

**S1｜核对改变范围**

当前 Agent 读取既有配置与报告，确认用户提供的新工具路径及受影响调用者。

**S2｜更新并检查**

修改指定字段，调用配置 Python 执行 yaya/tools/checks/check-project-environment.py --require-ready。

**S3｜追加记录**

在 reports/initialization.md 追加变更、实际检查、失败和提交，不重写历史初始化报告。

项目工具命令按以下约定执行：

- **工作目录**：实际游戏项目根目录。
- **Python 与调用形式**：使用 `docs/methodology-config.json` 中的 `python_executable`，调用形式为 `& $projectPython -B <脚本路径> <参数>`，每次立即检查 `$LASTEXITCODE`。
- **参数替换**：尖括号参数替换为实际值。
- **结果边界**：命令成功只证明该操作完成。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 本次环境差异明确 |
| S2 | 新位置可用且其他信息保留 |
| S3 | 新旧环境记录可区分 |

## 资源与文件影响

指定配置字段、初始化报告和必要 Progress 修改；不复制其他项目机器配置。

## 阻塞、异常与范围变化

新路径不可用时保留旧事实和当前失败，不静默选其他版本。

## 完成状态与验证标准

指定环境变更已生效并有当前检查，旧报告保留。
