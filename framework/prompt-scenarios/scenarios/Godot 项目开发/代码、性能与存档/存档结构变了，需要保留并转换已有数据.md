# 存档结构变了，需要保留并转换已有数据

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

例如背包从列表改成按格子存储，玩家已有的存档要转换成新结构后继续使用。

需要的材料：

- 获准使用的存档样本副本路径；不要提供唯一的真实存档。
- 必须保留的字段和允许损失的信息（原话即可）。
- 其余（旧新格式、读写实现、所属任务）由 Agent 直接读取。

## 前置条件与适用范围

数据变化已明确且由正式任务承接；玩家含义变化先在 GDD 中确认，并核对 Product 交付影响。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 代码、性能与存档 → 存档结构变了，需要保留并转换已有数据”。填入上述材料。本页使用 [$feature-execute](../../../../../project-source/skills/feature-execute/SKILL.md)。

**S1｜明确保留契约**

当前 Agent 核对真实旧样本、字段含义、默认值、信息损失与失败后保留方式。

**S2｜实现最小转换**

在所属任务（maintenance 或 Feature）中按获准结构做一次性或必要转换，不覆盖原件，不搭通用迁移平台。

**S3｜验证保留与失败**

比较转换前后需要保留的信息，核对新数据往返及异常样本，保留失败原件。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 每个旧字段的去向、默认值和允许损失已列成对照 |
| S2 | 样本副本转换后能被新结构读取，原件未改动 |
| S3 | 保留字段的前后比对、往返读写和异常样本的结果已记录 |

## 资源与文件影响

获准数据实现和样本副本修改；真实唯一存档与未授权个人数据不动。

## 阻塞、异常与范围变化

字段含义未定、无法满足已确认的保留要求，或信息损失超出已允许范围时，停止依赖部分并保留原件及失败样本。说明实际缺口和需要的取舍，不静默丢弃必须保留的信息或扩大数据访问；已明确允许的损失不另加无损转换门槛。

## 完成状态与验证标准

获准样本转换可用且必要信息保留，原件安全，转换限制和验证明确。
