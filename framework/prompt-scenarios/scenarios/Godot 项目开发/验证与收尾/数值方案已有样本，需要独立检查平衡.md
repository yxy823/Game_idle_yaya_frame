# 数值方案已有样本，需要独立检查平衡

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

数值方案已有样本，需要独立检查平衡。

需要的材料：

- 数值版本与目标：数值版本、目标曲线。
- 验证样本：真实或标明模拟的样本。

## 前置条件与适用范围

成果版本和权威要求明确，本次明确启用该领域独立审核。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 验证与收尾 → 数值方案已有样本，需要独立检查平衡”。填入上述材料。本页使用 [$review-balance](<../../../../../project-source/skills/review-balance/SKILL.md>)。

**S1｜交接审核材料**

主 Agent 向新上下文 independent-reviewer 交范围、版本、来源、原始证据与验证权限，作者总结仅作待核实陈述。

**S2｜按领域检查**

独立 Agent 使用 review-balance 核对资源流、策略差异、边界与体验目标，需要结论时取得参数和采样条件明确的样本。

**S3｜交付审核报告**

给出数值问题、样本局限与最小建议；成果、原件和验收只读，获准验证缓存和数据隔离。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 独立性与权限已核实 |
| S2 | 判断有领域适用证据 |
| S3 | 报告不代替用户人工验收 |

## 资源与文件影响

被审成果、原证据和验收记录只读；只写获准报告与隔离验证产物。

## 阻塞、异常与范围变化

- 证据不足：无法取得必要真实证据时明确未验证，不能以作者声明代替。
- 独立性不足：无法独立时说明限制。

## 完成状态与验证标准

该范围的独立报告已交付，数值问题、样本局限与最小建议明确，没有修复被审成果。

## 流程关联与衔接关系

审核意见经核实且已授权调整时，由主 Agent 使用[模型与参数调整](<../需求设计/已有数值需要调整，更新模型与参数.md>)处理所属数值来源；独立审核者保持只读，报告交付也不表示候选参数已经被采用。
