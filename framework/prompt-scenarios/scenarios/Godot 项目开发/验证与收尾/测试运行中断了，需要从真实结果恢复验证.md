# 测试运行中断了，需要从真实结果恢复验证

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

测试运行中断了，需要从真实结果恢复验证。

需要的材料：

- 运行入口与位置：原命令、运行目录。
- 中断现场：实际中断信息、当前进程状态。

## 前置条件与适用范围

测试未取得完整结束结果，不能假定仍在执行或已经通过。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 验证与收尾 → 测试运行中断了，需要从真实结果恢复验证”。填入上述材料。本页由当前 Agent 使用项目自己的 `verification-evidence-godot` Skill；[源码入口](<../../../../../project-source/skills/verification-evidence-godot/SKILL.md>)仅供核对。

**S1｜确认真实运行状态**

当前 Agent 核对实际进程和报告，不依赖旧会话句柄可续接的假设。

**S2｜保留并处理现场**

保留原日志，按现有工具规则终止获准残留或等待实际运行；中断结果不导入成功。

**S3｜重新验证缺口**

原因解除后，当前 Agent 使用 [project-verification-godot](<../../../../../project-source/skills/project-verification-godot/SKILL.md>) 重新运行必要范围并读取完整结果，再回到 `verification-evidence-godot` 导入当前有效整组引用。

调用示例的准备与限制：

- 位置与参数：在游戏项目根目录执行，将 `F0XX`、测试范围和运行编号换成实际值；以运行器输出的真实结果路径为准。
- 导入前提：先确认运行实际结束成功及报告完整。失败、零测试或中断不得作为成功结果导入。

```powershell
$projectConfig = Get-Content -LiteralPath 'docs/methodology-config.json' -Raw | ConvertFrom-Json
$projectPython = $projectConfig.python_executable
& $projectPython -B tools/testing/run-gdunit-tests.py --feature F0XX --scope affected
$LASTEXITCODE
& $projectPython -B tools/features/record-feature-completion.py record-tests --feature F0XX --run 'reports/gdunit-wrapper/F0XX/run-<实际编号>/result.json'
$LASTEXITCODE
& $projectPython -B tools/features/record-feature-completion.py show --feature F0XX
$LASTEXITCODE
```

参数与结果规则：

- 测试范围：`--scope` 按真实义务选择 `auto`、`required`、`affected` 或 `full`。
- 整组导入：多份结果必须在同一次 `record-tests` 调用重复提供 `--run <真实result.json>`，包括需要保留且相互兼容的全部运行。该命令用这一整组替换当前测试引用，不要拆成多次调用并假定累加。
- 导入失败：清除旧测试引用，但保留原始报告。
- 查看结果：`show` 仅用于查看匹配记录；读到记录不等于整个 Feature 完成。
- 免执行结果：仅在运行器按当前合法 manual 计划实际返回 `not_required` 时，说明本次不需要自动测试且没有运行报告，不导入不存在的原件或写成测试通过。既有失败和未完成结果仍按[测试规范](<../../../../../project-source/methodology/08-test-traceability-and-evidence.md>)处理；不能因证据失效或运行中断自行宣布免测。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 完成、运行中或中断可区分 |
| S2 | 没有把未完成结果当证据 |
| S3 | 恢复有真实结束证据 |

## 资源与文件影响

原失败日志保留；新运行与证据引用写入。

## 阻塞、异常与范围变化

无法判断进程归属或停止权限时仅报告具体对象，不按名称批量杀进程。

## 完成状态与验证标准

中断情况和剩余验证已处理，当前结论来自完整实际结果。
