# 方案有一个外部问题没确定，需要查资料

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

方案卡在一个项目里查不到答案的外部事实上，例如 Godot 4.7 的 `TileMapLayer` 是否支持某种碰撞写法、Windows 对存档路径的限制。

需要的材料（对应提示词的三个输入）：

- 要确认什么，以及答案影响哪个选择。
- 已有资料与限制：相关文件、目标版本和平台；项目里能读到的版本和约束不用重复填写。
- 输出偏好：只在对话返回、由 Agent 判断是否留存，或指定 `docs/research/` 下的报告文件。

## 前置条件与适用范围

需要外部事实或方案依据，本次不做本地实现。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 游戏想法与 GDD → 方案有一个外部问题没确定，需要查资料”。填入上述材料。

**S1｜限定调查问题**

当前 Agent 核对已知条件，按需使用 researcher；小问题可直接查询，不建立额外研究流程。

**S2｜查证一手材料**

核对官方文档、源码或原论文及版本，区分实际结果、来源说法和推断。

**S3｜交付建议**

- 结论：说明可用方案、限制和仍需实验验证的假设。简单查询直接返回结论，不强制写报告。
- 研究报告：有保存价值且本次授权写报告时，保存到 `docs/research/<用途明确的主题>.md`，复用相同主题报告。
- 临时材料：草稿与资料摘录保存在项目根目录 `tmp/<任务>/`；原始下载与探针放 `reports/scratch/<任务>/`。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 问题、目标版本和答案影响的选择已写明 |
| S2 | 结论有可定位出处 |
| S3 | 外部未知项已回答或明确缺口 |

## 资源与文件影响

外部材料和项目背景只读；仅写获准研究报告。

## 阻塞、异常与范围变化

页面不可读、版本不符或代码抽取异常时换有效来源并说明限制，不凭摘要补齐。

## 完成状态与验证标准

调查结论及适用版本、依据和未决项明确，没有执行本地实验。

## 流程关联与衔接关系

研究报告归属按 [researcher 角色契约](../../../../../project-source/agents/researcher.toml)执行。
