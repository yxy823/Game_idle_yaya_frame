# 外部调研还没结束，继续查清原来的问题

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

上次查 Godot 某个 API 的行为查到一半就停了，`docs/research/` 里留着半份报告，还有两个子问题没有答案，现在要接着查完。

需要的材料：原报告路径，或说明是哪次调研（Agent 也会从 Progress 找）；这次要不要更新原报告，不写时沿用原任务的输出约定。目标版本有变化时写明新版本；原问题、已读来源和未决项由 Agent 从报告和 Progress 读取。

## 前置条件与适用范围

原任务是尚未完成的外部调研，没有 Feature；用户明确继续原问题。

## 执行步骤

使用[预设提示词库](../../../prompts/godot-development-prompts.json)中的“Godot 项目开发 → 现状、暂停与续接 → 外部调研还没结束，继续查清原来的问题”。

**S1｜恢复调查边界**

当前 Agent 核对 docs/research/ 中原报告或已保存来源、实际问题和已知结论，区分读过的原文与搜索摘要。

**S2｜继续查证缺口**

按原分工由当前 Agent 或 researcher 针对尚未解决的问题查一手来源，复用仍适用结果，不重复无关检索；变化版本重新核实。

**S3｜更新原输出**

返回有出处的结论及局限；获准写报告时更新原 `docs/research/` 文件。临时草稿与资料摘录放项目根目录 `tmp/<任务>/`，原始下载和探针放 `reports/scratch/<任务>/`。

## 步骤产出与状态变化

| 步骤 | 继续条件 |
| --- | --- |
| S1 | 已证实部分和未决项清楚 |
| S2 | 已完成必要查证，取得新证据，或确认当前不可获得的证据及恢复条件 |
| S3 | 结论已在对话返回，或原 `docs/research/` 报告已更新 |

## 资源与文件影响

外部来源与项目实现只读；只写获准研究报告和原始资料，不写需求、任务状态或验收。

## 阻塞、异常与范围变化

访问、版本或证据不足时说明限制；调查请求不授权本地实现实验。

## 完成状态与验证标准

原问题在授权范围已得到有依据的结论；或已完成必要查证，确认剩余问题因当前不可获得的证据无法继续，并说明具体缺口与恢复条件。既有有效调查不重复。
