# 收到 Codex 的回复，想判断并写出下一条指令

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

收到 Codex 的回复，想判断并写出下一条指令。

需要的材料：

- 原任务与目标：原任务、有效授权和希望达到的结果。
- 待判断输出：Codex 原输出。

## 前置条件与适用范围

本次需要只读指导，未要求执行建议。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 日常开发 → 收到 Codex 的回复，想判断并写出下一条指令”。填入上述材料。本页使用 [$project-next-step-advisor](<../../../../../project-source/skills/project-next-step-advisor/SKILL.md>)。

**S1｜核对输出声明**

当前 Agent 用 advisor 对照原任务与项目证据，判断结论、建议和停点是否成立。

**S2｜起草可发送回复**

先说明必要纠正，再由 advisor 从本机共享 Godot 开发提示词库中选择适用场景，说明名称及理由，填入当前事实生成具体续接指令，包含范围、适用 Skill 和真实停止条件。没有匹配条目时，区分输入缺失、可适配场景和真实覆盖缺口，提出必要的补充建议，不修改共享库。

## 资源与文件影响

项目文件、原始证据和共享 Godot 提示词库只读；输出在对话。

## 阻塞、异常与范围变化

原件缺失时说明限制，不把摘要当已验证结果。

## 完成状态与验证标准

判断与可复制回复已交付，没有自动发送或执行。
