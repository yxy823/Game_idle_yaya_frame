# 想知道项目现在做到哪里

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

例如隔了几天回来，想先弄清各个 Feature 停在哪里、哪些在等人工验收，暂时不需要下一步建议。

需要的材料：

- 关注的模块或疑问（可选）：例如“Product 02 做到哪了”。不提供时看整个项目。

## 前置条件与适用范围

只想知道现状，不需要下一步建议；需要建议时用[想了解项目当前进度，并确定下一步](想了解项目当前进度，并确定下一步.md)。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 日常开发 → 想知道项目现在做到哪里”。填入上述材料。本页使用 [$project-next-step-advisor](<../../../../../project-source/skills/project-next-step-advisor/SKILL.md>)。

**S1｜读取当前事实**

当前 Agent 使用 project-next-step-advisor 读取相关 Progress、Feature 和真实证据，只补读必要文件。

**S2｜说明实际进展**

区分需求、计划、实现、验证、待人工与完成，指出阻塞和已明确决定。

## 资源与文件影响

项目文件和原始证据只读；输出在对话。

## 阻塞、异常与范围变化

原件缺失时说明限制，不把摘要当已验证结果。

## 完成状态与验证标准

当前进度与证据缺口已说明，没有执行后续动作。
