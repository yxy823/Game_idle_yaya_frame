# 想了解项目当前进度，并确定下一步

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

想了解当前项目或指定模块做到哪里，并据此决定下一步。可以补充关注范围、当前疑问和已有决定；未指定模块时查看当前项目，可从项目读取的信息无需重复提供。

## 前置条件与适用范围

适用于正常推进、暂停、等待验收或遇到阻塞时的进度与下一步查询，不要求已经停住。本次只提供指导，不执行建议；只想查询进度时使用[想知道项目现在做到哪里](想知道项目现在做到哪里.md)。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 日常开发 → 想了解项目当前进度，并确定下一步”。填入上述材料。本页使用 [$project-next-step-advisor](<../../../../../project-source/skills/project-next-step-advisor/SKILL.md>)，由当前 Agent 只读处理。

**S1｜说明当前进度**

使用 advisor 核对当前记录及必要原始证据，概括已计划、已实现、已验证、待人工验收和已完成的实际状态，说明阻塞及证据缺口。无法核实处保留未知，不把旧报告或测试通过单独当作当前交付完成。

**S2｜推荐下一步**

根据当前进度与有效授权，按现有路由确定优先动作，再由 advisor 从本机共享 Godot 开发提示词库中核对适用场景。说明选中的分类、场景、理由、对应 Skill、最少所需材料、必要决定和预期结果。需要帮助发起下一动作时，填入当前事实起草可复制指令，不自动发送或执行。

没有匹配场景时，区分缺少输入、现有条目可以适配和真实覆盖缺口。只有目标未覆盖或执行边界明显不同，才提出场景补充建议，说明最接近条目和差异，不修改共享库；当前无需后续动作时说明依据，不为凑建议增加任务。

## 资源与文件影响

项目文件、原始证据和共享 Godot 提示词库只读；输出在对话。

## 阻塞、异常与范围变化

原件缺失时说明限制，不把摘要当已验证结果。

## 完成状态与验证标准

当前进度和证据缺口已说明，下一步建议有真实依据且能从当前状态衔接；无后续动作时理由明确。本次没有修改项目或执行建议。

## 流程关联与衔接关系

依据：[项目路由依据](<../../../../../project-source/methodology/00-overview.md>)。本次查询到说明与建议交付为止，不因旧实施授权自动继续开发。用户后续明确要求实施时，沿用仍有效的具体授权进入对应流程；建议交付不代表 Feature 已完成，也不代替实际人工接受。
