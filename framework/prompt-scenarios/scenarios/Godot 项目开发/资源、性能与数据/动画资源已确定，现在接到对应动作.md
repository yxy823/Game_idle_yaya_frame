# 动画资源已确定，现在接到对应动作

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

例如美术已交付角色受击动画，需要在受击时播放、结束后回到待机。

需要的材料：

- 动画文件路径，以及要接的动作事件或状态（例如“受击时播放 hit，结束后回到 idle”）。
- 其余（所属 Feature 或实验、确认的规格、所属资源章节）由 Agent 直接读取。

## 前置条件与适用范围

文件和消费目标已经确认，当前已授权的 Feature 或限定范围的实验包含这次接入。两者都没有时不修改运行时文件，先按任务路由选择入口。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 资源、性能与数据 → 动画资源已确定，现在接到对应动作”。填入上述材料。当前 Agent 使用 [$content-asset-integration](../../../../../project-source/skills/content-asset-integration/SKILL.md) 接入；验证和完成回到调用它的任务：Feature 内是 [$feature-execute](../../../../../project-source/skills/feature-execute/SKILL.md)，独立实验是 [$prototype-godot](../../../../../project-source/skills/prototype-godot/SKILL.md)。

**S1｜核对接入契约**

当前 Agent 使用 content-asset-integration 核对轨道、时长、循环、骨骼或帧引用，确认实际消费者及文件来源。

**S2｜接入当前消费对象**

只把获准动画接入指定节点或事件，维护实际导入设置和必要引用，不改上游要求。最终验证前，到所属资源章节更新准备状态、实际资源路径和使用方路径。

**S3｜验证实际反馈**

回到调用的任务（feature-execute 或 prototype-godot），在获准运行范围检查动作启动、结束、打断与状态切换；真实视觉结果由用户体验确认。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 轨道、时长、循环与规格逐项比对，不符项已列出 |
| S2 | 目标节点或状态已引用新动画；所属资源章节已写入实际路径和使用方 |
| S3 | 运行检查结果和用户视觉确认分别记录 |

## 资源与文件影响

- 修改：动画资源及其导入设置、场景或脚本引用、所属资源章节中的准备状态、实际资源路径和使用方路径。
- 保留：原规格与外部原件。

## 阻塞、异常与范围变化

文件缺失、规格冲突或来源不清时停在对应缺口；不在此制作素材或改变目标要求。

## 完成状态与验证标准

新增动画已接到指定动作，所属资源章节已更新；运行检查结果与用户视觉确认结果分别写明，未确认的检查明确列出。
