# 音效文件和播放位置都已确定，现在要把声音接进游戏

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

音效文件和播放位置都已确定，现在要把声音接进游戏。

需要的材料：

- 任务与音效：当前 Feature、已获准音效。
- 播放要求：播放事件、声音规格。

## 前置条件与适用范围

文件和消费目标已经确认，当前 Feature 或工程任务已授权新增音效。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 资源、性能与数据 → 音效文件和播放位置都已确定，现在要把声音接进游戏”。填入上述材料。本页使用 [$content-asset-integration](<../../../../../project-source/skills/content-asset-integration/SKILL.md>)、[$feature-execute](<../../../../../project-source/skills/feature-execute/SKILL.md>)。

**S1｜核对接入契约**

当前 Agent 使用 content-asset-integration 核对格式、循环和导入后可播放性，确认实际消费者及文件来源。

**S2｜接入当前消费对象**

只把获准资源接入指定节点或事件，维护实际导入设置和必要引用，不改上游要求。

**S3｜验证实际反馈**

返回 feature-execute，在获准运行范围检查实际事件触发、音量/混音、停止与重复播放，真实视觉或听觉结果由用户体验确认。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 输入资源适合当前消费目标 |
| S2 | 实际资源引用有效 |
| S3 | 实际体验与自动检查分别记录 |

## 资源与文件影响

- 修改：对应资源、场景/脚本引用、必要导入设置和原清单实际位置。
- 保留：原规格与原件。

## 阻塞、异常与范围变化

文件缺失、规格冲突或来源不清时停在对应缺口；不在此制作素材或改变目标要求。

## 完成状态与验证标准

新增音效已完成，指定消费关系有效，适用运行与体验结果明确，原任务剩余完成检查可继续。
