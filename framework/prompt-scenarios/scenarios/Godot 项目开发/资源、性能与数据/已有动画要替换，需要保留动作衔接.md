# 已有动画要替换，需要保留动作衔接

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

已有动画要替换，需要保留动作衔接。

需要的材料：

- 替换资源：旧新动画。
- 动作与消费关系：状态机、事件轨道和共享消费者。

## 前置条件与适用范围

文件和消费目标已经确认，当前已授权的 Feature 或限定范围的实验包含替换动画。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 资源、性能与数据 → 已有动画要替换，需要保留动作衔接”。填入上述材料。本页使用 [$content-asset-integration](<../../../../../project-source/skills/content-asset-integration/SKILL.md>)、[$feature-execute](<../../../../../project-source/skills/feature-execute/SKILL.md>)。

**S1｜核对接入契约**

当前 Agent 使用 content-asset-integration 核对轨道绑定、名称、时长与事件时序，确认实际消费者及文件来源。

**S2｜更新资源并保留消费关系**

保留必要旧信息后更新资源及引用，检查所有共享消费者，不仅替换看到的一个文件。

**S3｜验证实际反馈**

返回 feature-execute，在获准运行范围检查过渡、打断和相关动作状态的运行反馈，真实视觉或听觉结果由用户体验确认。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 输入资源适合当前消费目标 |
| S2 | 实际资源引用有效 |
| S3 | 实际体验与自动检查分别记录 |

## 资源与文件影响

- 修改：对应资源、场景/脚本引用、必要导入设置和原清单实际位置。
- 保留：原规格与原件。

## 阻塞、异常与范围变化

文件缺失、规格冲突或来源不清时停在对应缺口；不在此制作素材或改变目标要求。

## 完成状态与验证标准

替换动画已完成，指定消费关系有效，适用运行与体验结果明确，原任务剩余完成检查可继续。
