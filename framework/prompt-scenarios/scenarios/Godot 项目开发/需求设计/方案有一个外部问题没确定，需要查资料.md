# 方案有一个外部问题没确定，需要查资料

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

方案有一个外部问题没确定，需要查资料。

需要的材料：

- 调查问题与版本：待回答问题、适用版本。
- 约束与证据要求：约束、可接受的证据来源。

## 前置条件与适用范围

需要外部事实或方案依据，本次不做本地实现。

## 执行步骤

使用[集中提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 需求设计 → 方案有一个外部问题没确定，需要查资料”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页由当前 Agent 使用现有规则和工具处理；需要独立审核的步骤明确交给独立实例。

**S1｜限定调查问题**

当前 Agent 核对已知条件，按需使用 researcher；小问题可直接查询，不建立额外研究流程。

**S2｜查证一手材料**

核对官方文档、源码或原论文及版本，区分实际结果、来源说法和推断。

**S3｜交付建议**

- 结论：说明可用方案、限制和仍需实验验证的假设。简单查询直接返回结论，不强制写报告。
- 研究报告：有保存价值且本次授权写报告时，使用指定的项目内路径；未指定时保存到 `docs/research/<用途明确的主题>.md`，复用相同主题报告。
- 临时材料：草稿与资料摘录保存在项目根目录 `tmp/<任务>/`；原始下载与探针放 `reports/scratch/<任务>/`。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 调查能支持一个具体决定 |
| S2 | 结论有可定位出处 |
| S3 | 外部未知项已回答或明确缺口 |

## 资源与文件影响

外部材料和项目背景只读；仅写获准研究报告。

## 阻塞、异常与范围变化

页面不可读、版本不符或代码抽取异常时换有效来源并说明限制，不凭摘要补齐。

## 完成状态与验证标准

调查结论及适用版本、依据和未决项明确，没有执行本地实验。
