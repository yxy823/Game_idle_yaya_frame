# 已确认的声音方向要调整，需要更新规范并检查影响

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

已确认的声音方向要调整，需要更新规范并检查影响。

准备材料：

- 方向变更：原规范、已确认的新决定。
- 影响对象：适用对象和已有资源/Feature。

## 前置条件与适用范围

已有有效共享声音方向；本次修改已确认要求并说明消费者影响，不重新启动初次风格访谈。

## 执行步骤

使用[集中提示词库](../../../prompts/godot-development-prompts.json)中的“Godot 项目开发 → 需求设计 → 已确认的声音方向要调整，需要更新规范并检查影响”。适用 Skill：[$design-audio-direction](../../../../../project-source/skills/design-audio-direction/SKILL.md)。

**S1｜核对方向差异**

当前 Agent 使用 design-audio-direction 读取原规范与新决定，核对 声音角色、混音关系、循环疲劳、过渡和适用场景 中实际变化；玩家行为改变先由 GDD 承接，并核对 Product 交付范围。

**S2｜修改唯一规范**

共享声音规格固定维护在 `docs/audio/sound-bible.md`，更新受影响规格、适用范围和引用；原先写在 GDD 的当前范围内规格迁入该文件，GDD 保留整体体验目标、玩法触发规则及引用。保留未改变的有效决定与真实历史。

**S3｜核对消费者并交接**

追查专业规格、素材、实际实现和已规划任务的适用关系，列需同步的计划及后续资源工作。只交接影响，不在本页替换素材或直接实现。

## 步骤产出与状态变化

| 步骤 | 继续条件 |
| --- | --- |
| S1 | 变化属于明确的专业来源 |
| S2 | 新要求形成可定位来源 |
| S3 | 新来源与既有消费者的差异明确 |

## 资源与文件影响

docs/audio/sound-bible.md 与必要来源链接修改；现有素材、运行实现和已完成 Feature 的 AC/验收历史只读。

## 阻塞、异常与范围变化

对新方向仍未作实质决定时只补齐对应选择；不能修改来源来把旧实现 Bug 改写成符合要求。

## 完成状态与验证标准

确认的新声音方向已保存，受影响消费者及待同步计划明确；资源制作与实现未被冒称完成。
