# 已有内容表现不对，先判断是 Bug、要改要求还是只需调值

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

已经做出来的内容让你觉得不对，但说不清该修 Bug、改要求还是只调个数值。例如：

- 已验收的棋盘下落太慢。
- GDD 写着升级消耗按等级翻倍，游戏里却是固定值。
- Feature 记录标着已完成，对应功能却找不到。

现在要先弄清它属于哪一类、该交给哪个入口。

准备材料：

- 不对的地方：哪项内容在什么情况下表现不对，或哪份文档或记录（路径或 Feature ID）和哪处实际表现对不上，用原话描述差异。
- 已有运行证据：截图、日志或复现步骤；没有就不填，由 Agent 只做静态核对。
- 你记得的相关决定：例如“上次讨论已改成固定值”；没有就不填。

文档、实现、调参资源、Feature 记录和 Git 历史由 Agent 直接读取。

## 前置条件与适用范围

反馈可以来自任何来源，不要求曾有手工修改或可用 diff；本次只核实反馈并确定去向，不修复、不改要求、不调值。只读处理不运行 Godot、不写探测代码。

## 执行步骤

使用[预设提示词库](../../../prompts/godot-development-prompts.json)中的“Godot 项目开发 → 出了问题 → 已有内容表现不对，先判断是 Bug、要改要求还是只需调值”。

**S1｜弄清反馈与双方事实**

当前 Agent 使用 [feedback-triage](../../../../../project-source/skills/feedback-triage/SKILL.md)，确定实际观察、预期结果、触发条件和受影响版本；读取实际文档、代码、调参资源、Feature 记录或运行原件，区分正式要求、当前实现、历史结果和 Agent 摘要。

**S2｜判断类别**

根据用户确认、来源版本和实际历史，判断属于下列哪一类；代码存在不批准新需求，证据冲突时展示分歧，不挑方便的一方：

| 类别 | 判断依据 | 转交的入口 |
| --- | --- | --- |
| 有依据的缺陷 | 实现违反仍有效的要求 | [发现 Bug，需要修复](<发现 Bug，需要修复.md>)；先查原因时用[发现异常，先定位原因，不修改实现](<发现异常，先定位原因，不修改实现.md>) |
| 需求发生了变化 | 实现符合当时的要求，用户现在想要不同的结果 | 先改权威来源，再用[要求已经改好，同步受影响的 Feature](<../要求变了/要求已经改好，同步受影响的 Feature.md>) |
| 只需调观感数值 | 规则和结果都符合要求，只是速度、节奏、手感等观感参数不合适（按 13 号规范的[选择方式](../../../../../project-source/methodology/13-debug-console-and-validation.md#选择方式)判断） | 所属 Feature 已完成时用[已完成的内容要再调速度、节奏或手感](<../实施与调参/已完成的内容要再调速度、节奏或手感.md>)；未完成时用所属 Feature 中的调参入口 |
| 能力已经存在 | 功能在，只是入口或说明难找 | 给出实际入口和局限即可结束 |
| 文档或记录不符 | 文档过期、记录错误 | 说明唯一权威正文与正确的记录落点 |
| 证据缺口 | 现有证据不足以判断 | 说明缺少的具体材料 |

**S3｜给出下一个负责方**

说明类别、支撑的来源或观察、重要的不确定之处、应该更新的唯一正文或实现位置、必须保留的历史、下游同步、转交的入口及必要验证；不直接按当前代码改 AC。简短回答够用时不另建报告文件。

## 步骤产出与状态变化

| 步骤 | 继续条件 |
| --- | --- |
| S1 | 反馈的观察、预期和触发条件已写明；相关双方的原文位置和实际内容已列出，各自标明是正式要求、当前实现、历史记录还是摘要 |
| S2 | 已判定为上表的一类，并引用支撑的来源版本或用户决定 |
| S3 | 应修改的文件或记录、需保留的历史和转交的入口已写明 |

## 资源与文件影响

相关文档、实现、调参资源、历史和证据只读；分析不改 Product、AC、实现、调参资源或验收记录。

## 阻塞、异常与范围变化

有效来源或历史不足时保留尚未确定的状态，指出所需证据和可继续核对的位置；没有观察到的故障保持“未确认”，不等于已被否定。不能以让文档相等为目标重写接受记录。

## 完成状态与验证标准

反馈的类别和应处理位置已有可核实依据，下一个负责方已写明，没有静默选择实现或文档一方为正确。
