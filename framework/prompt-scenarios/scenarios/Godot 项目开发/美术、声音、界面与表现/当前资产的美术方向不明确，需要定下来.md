# 当前资产的美术方向不明确，需要定下来

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

GDD 已写明体验要“平静、奖励易于辨认”，准备做角色和道具图标，但还没定形状、配色和细节处理，素材规格无从下手。

需要的材料：

- 要覆盖的资产族，例如“角色立绘与道具图标”。
- 参考（链接或图片），写明想借鉴的是哪一点；没有参考时，Agent 只按 GDD 的体验目标提出方案。
- 显示条件：目标分辨率或屏幕尺寸、镜头距离；不写时 Agent 从项目配置和 UI 规格读取，读不到就标为缺口。

目标体验和已确认的玩法行为由 Agent 从 GDD 读取。

## 前置条件与适用范围

GDD 已写明当前范围的体验目标，不要求完整；需要补足当前范围可实施的专业规范。

## 执行步骤

使用[预设提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 美术、声音、界面与表现 → 当前资产的美术方向不明确，需要定下来”。填入上述材料。本页使用 [$design-art-direction](<../../../../../project-source/skills/design-art-direction/SKILL.md>)。

**S1｜收集专业依据**

当前 Agent 使用 design-art-direction 读取 GDD 已有设计、已确认行为与参考，区分偏好和必须满足的约束。

**S2｜确定当前方向**

围绕形状、色彩、对比、材质和适用资产范围提出取舍，与用户确认影响结果的关键选择。

**S3｜维护唯一规范**

共享美术规格与专业决定固定写入 `docs/art/art-bible.md`；原先写在 GDD 的当前范围内规格迁入该文件并更新引用，GDD 保留整体体验目标。明确适用对象并核对已有消费者影响。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | GDD 体验目标、参考与显示条件已列出，偏好与硬约束已分开 |
| S2 | 关键选择已由用户确认，未决项已标明 |
| S3 | `art-bible.md` 已写入并注明适用资产族；GDD 中被迁出的规格已改为链接 |

## 资源与文件影响

`docs/art/art-bible.md` 及必要 GDD 引用修改；其他专业规格按需链接，本页不制作或接入素材。

## 阻塞、异常与范围变化

没有在目标显示条件下看过实际画面时，明确方向尚未经过画面验证；不能宣称专业体验已经通过。

## 完成状态与验证标准

当前范围的方向已确认、保存并明确适用对象，制作和接入未冒充完成。
