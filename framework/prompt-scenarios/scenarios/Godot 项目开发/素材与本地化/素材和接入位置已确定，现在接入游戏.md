# 素材和接入位置已确定，现在接入游戏

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

一份新的音效、图片或动画已经交付，接到哪里也已确认，需要接进游戏。例如：

- 购买成功的音效文件已交付，声音规格中的播放时机已确认。
- 美术已交付商店按钮图标，UI 规格中的位置已确认。
- 美术已交付角色受击动画，需要在受击时播放、结束后回到待机。

背景音乐有切换时机，改用[音乐文件和切换时机已确定，现在接入背景音乐](<音乐文件和切换时机已确定，现在接入背景音乐.md>)；场景文件有依赖，改用[场景文件及依赖已准备好，现在接入当前游戏](<场景文件及依赖已准备好，现在接入当前游戏.md>)。

需要的材料：

- 素材类型和文件路径。
- 接入位置：音效写触发它的播放事件（例如“购买成功时播放”）；图片写要放到的界面节点（场景路径或界面名称）；动画写要接的动作事件或状态（例如“受击时播放 hit，结束后回到 idle”）。
- 其余（所属 Feature 或实验、确认的规格、所属资源章节）由 Agent 直接读取。

## 前置条件与适用范围

文件和消费目标已经确认，当前已授权的 Feature 或限定范围的实验包含这次接入。两者都没有时不修改运行时文件，先按任务路由选择入口。

## 执行步骤

使用[预设提示词库](<../../../prompts/godot-development-prompts.json>)中的“Godot 项目开发 → 素材与本地化 → 素材和接入位置已确定，现在接入游戏”。填入上述材料。当前 Agent 使用 [$content-asset-integration](../../../../../project-source/skills/content-asset-integration/SKILL.md) 接入；验证和完成回到调用它的任务：Feature 内是 [$feature-execute](../../../../../project-source/skills/feature-execute/SKILL.md)，作为调试台候选接入时是 [$in-game-tuning](../../../../../project-source/skills/in-game-tuning/SKILL.md)。

各步骤按素材类型核对的内容不同：

| 步骤 | 音效 | 图片 | 动画 |
| --- | --- | --- | --- |
| S1 核对 | 格式、循环和导入后可播放性 | 尺寸、透明、切片及导入设置 | 轨道、时长、循环、骨骼或帧引用 |
| S2 接入 | 接到指定事件，维护音频路由 | 接到指定节点 | 接到指定节点或事件 |
| S3 运行检查 | 实际事件触发、音量与混音、停止与重复播放 | 目标分辨率下的显示、缩放、边缘与状态变化 | 动作启动、结束、打断与状态切换 |
| 用户确认 | 试听 | 视觉 | 视觉 |

**S1｜核对接入契约**

当前 Agent 使用 content-asset-integration 按上表核对文件，与对应规格逐项比对，确认实际消费者及文件来源。

**S2｜接入当前消费对象**

只把获准素材接入指定位置，维护实际导入设置和必要引用，不改上游要求。最终验证前，到所属资源章节更新准备状态、实际资源路径和使用方路径。

**S3｜验证实际反馈**

回到调用的任务（feature-execute 或 in-game-tuning），在获准运行范围按上表检查运行反馈；真实听觉或视觉结果由用户体验确认。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 上表的核对项与规格逐项比对，不符项已列出 |
| S2 | 指定事件、节点或状态已使用新素材；所属资源章节已写入实际路径和使用方 |
| S3 | 运行检查结果和用户试听或视觉确认分别记录 |

## 资源与文件影响

- 修改：素材资源及其导入设置、场景或脚本引用、音频路由（音效）、所属资源章节中的准备状态、实际资源路径和使用方路径。
- 保留：原规格与外部原件。

## 阻塞、异常与范围变化

文件缺失、规格冲突或来源不清时停在对应缺口；不在此制作素材或改变目标要求。

## 完成状态与验证标准

新增素材已接入指定位置，所属资源章节已更新；运行检查结果与用户试听或视觉确认结果分别写明，未确认的检查明确列出。
