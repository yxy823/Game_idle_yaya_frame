# 场景速查索引

按“现在遇到了什么情况”找到对应的场景页。每篇场景页对应提示词库中一条同名的提示词：[Godot 项目开发](../prompts/godot-development-prompts.json)、[Yaya 框架维护](../prompts/yaya-maintenance-prompts.json)。

## 怎样使用场景页

先确认在哪里执行：

- 「Godot 项目开发」的场景在游戏项目目录中执行，页内路径相对游戏项目根目录。例外是「准备开始新游戏，先创建空白项目」：这时游戏项目还不存在，在本框架仓库运行创建器。
- 「Yaya 框架维护」的场景在本框架仓库中执行。

两类操作不能混在一起。

所有场景页都遵循以下约定，页内不再逐篇重复：

- **只查当前需要的那一篇**：场景页不是要依次执行的清单。
- **发送提示词**：新对话中复制场景页指定的提示词，填好材料后发送；已在进行中的对话不需要重新发送，直接补齐材料即可。补充要求写希望达到的结果，具体做法作为建议，例如写“窗口边缘与背景同色”，而不只写“把清屏色设为背景色”。
- **默认执行者**：页内没有特别说明时，由当前 Agent 使用项目已有的规则和工具执行；需要独立审核的步骤会在页内明确交给独立实例。
- **授权会延续**：用户已给出的具体授权在各场景之间一直有效，不需要因为换了一篇场景页而重新确认。
- **出口之后**：到达场景页的出口后，已获授权的后续工作转到它所属的场景继续。
- **出口不等于交付**：准备、诊断、规划或记录完成，都不代表 Feature 已正式完成。只读的分析、建议或验证结论也不会扩大授权范围。
- **人工接受要真实取得**：任何场景都不能代替用户的实际验收结果。
