# 想先总览框架，再选择审核专题

[返回场景索引](../../scenario-index.md#只读专项审核) · [通用模板](专项审核通用模板.md)

## 触发场景与使用时机

希望审核 Agent 先了解框架结构，帮助选择下一次值得深入的审核专题。已经有明确问题时，可以直接从[专项入口](../../scenario-index.md#只读专项审核)选择，不必先做总览。

## 前置条件与适用范围

本专题回答的问题：框架由哪些部分组成，各部分的职责和入口是什么；哪些区域最值得做专项审核。

具体范围、必读来源和检查要点都写在提示词里，无需填写参数。审核只读，不修改任何文件。

## 执行步骤

**S1｜拼接并发送提示词**

1. 打开一个新对话；这个对话不能参与过被审内容的修改。
2. 复制[Yaya 框架维护提示词库](../../../prompts/yaya-maintenance-prompts.json)中的「只读专项审核 → 专项审核通用模板」。
3. 把「只读专项审核 → 想先总览框架，再选择审核专题」的内容粘贴到模板末尾的「本次专题」下方。
4. 发送。

**S2｜等待审核报告**

审核 Agent 按专题范围只读核对，在对话中交付报告。需要留存时，明确要求保存到 `tmp/reports/<任务>/`。

**S3｜决定后续处理**

阅读报告，自行决定哪些问题要修、修到什么范围；审核结论本身不授权修改。

## 完成状态与验证标准

收到结构概览和 1–3 个推荐专题，每个推荐都有具体文件依据。总览不是全面审核，也不会自动开始任何专项。

## 流程关联与衔接关系

选定专题后使用[对应专项入口](../../scenario-index.md#只读专项审核)；已有报告需要判断是否修改时，使用[外部意见复核](<../维护与复盘/收到外部审核意见，先核实哪些值得修改.md>)。
