# 专项审核通用模板

[返回场景索引](../../scenario-index.md#只读专项审核)

## 触发场景与使用时机

要做任何一个只读专项审核时，先取这份模板。它保存所有专项审核共用的规则：只读授权、判定标准、具体任务推演、报告结构、完成与停止条件；各专题只保存自己的审核问题、范围、必读来源和检查要点。

## 前置条件与适用范围

模板不能单独使用，必须与「只读专项审核」分类下的一条专题条目拼接。可拼接的专题见场景索引的[只读专项审核](../../scenario-index.md#只读专项审核)。

## 执行步骤

**S1｜复制模板**

复制[Yaya 框架维护提示词库](../../../prompts/yaya-maintenance-prompts.json)中「只读专项审核 → 专项审核通用模板」的全文。

**S2｜粘贴专题**

把选定专题条目的全文粘贴到模板末尾「本次专题」标题下方，替换「（在下方粘贴一条专题内容）」这一行。一次只粘贴一个专题。专题带 `${}` 占位时（例如[框架好像有问题，先判断从哪里查起](<框架好像有问题，先判断从哪里查起.md>)的「本次线索」），按占位说明填写或留空；其他专题不需要填参数。

**S3｜在新对话中发送**

在没有参与过被审内容修改的新对话中发送拼接后的提示词。

## 资源与文件影响

| 对象 | 影响 |
| --- | --- |
| 被审仓库 | 只读，不修改 |
| `tmp/reports/<任务>/` | 仅在明确要求保存报告时写入 |

## 完成状态与验证标准

拼接后的提示词包含模板的全部字段和一个完整专题；发送后由对应专题页说明完成标准。要求保存报告时，审核 Agent 的最终回复先给报告路径和结论摘要，不另套完成汇报的小标题。

## 流程关联与衔接关系

修改模板会影响全部专项审核；只影响某一专题的内容写在该专题条目中，不放进模板。
