# 新增能力的方案已确定，现在修改框架

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

新增能力的方案已确定，现在修改框架。需要的材料：

- **实施依据**：已确认方案。
- **写入与验证范围**：具体写入范围、允许验证方式与外部验证项目。

## 前置条件与适用范围

方案与实施边界已经明确，本次完成所选能力。

## 执行步骤

使用[集中提示词库](<../../../prompts/yaya-maintenance-prompts.json>)中的“Yaya 框架维护 → 设计与借鉴 → 新增能力的方案已确定，现在修改框架”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页由当前 Agent 使用现有规则和工具处理；需要独立审核的步骤明确交给独立实例。

**S1｜核对方案与调用链**

当前 Agent 对照根 AGENTS.md、复制清单和受影响工具读取当前实现，复用已确认决定。

**S2｜完成最小实现**

修改获准维护源，追到读写方、配置、复制映射、说明和适用回归；不自动同步生成项目。

**S3｜验证并交付**

执行与影响相称且获准的检查，保留实际结果，核对完整差异后按根规则本地提交。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 改动对象与契约一致 |
| S2 | 实现与调用链全部同步 |
| S3 | 提交及真实检查结论可定位 |

## 资源与文件影响

所选维护源与必要说明、回归会修改；生成项目仅在明确指定验证范围内使用。

## 阻塞、异常与范围变化

方案实质扩展时仅暂停依赖新增决定的部分；验证失败不写成完成。

## 完成状态与验证标准

选定能力已实现，相关调用与说明一致，适用验证完成并交付本地提交。
