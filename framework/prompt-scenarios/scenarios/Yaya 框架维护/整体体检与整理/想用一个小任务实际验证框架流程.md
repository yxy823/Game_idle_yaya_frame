# 想用一个小任务实际验证框架流程

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

改完 Skill 或方法规范后，想在一个外部项目里从已有 GDD 出发，实际走一遍 Product、Feature 规划和实现，看流程能否走通。需要的材料：

- **验证项目**：已存在的外部项目绝对路径，以及项目内 GDD 的入口。
- **微型任务**：GDD 中已确认、范围足够小的设计内容和交付边界。
- **报告保存**（可选）：默认在对话中输出；要保存时给出任务名，报告放在本仓库 `tmp/reports/<任务>/`，文件名带日期，不提交。

被测文件是否对应当前框架版本，由 Agent 核对。

## 前置条件与适用范围

已授权指定外部验证项目、GDD 中已有的微型交付和运行范围；项目已采用本次被测文件且有真实 GDD，框架源只读。本次不覆盖创建器、GDD 初始化、续接和迁移检查。

## 执行步骤

使用[集中提示词库](<../../../prompts/yaya-maintenance-prompts.json>)中的“Yaya 框架维护 → 整体体检与整理 → 想用一个小任务实际验证框架流程”。填入上述材料。

**S1｜核对验证项目**

- **核对输入**：当前 Agent 确认指定项目路径、真实 GDD 和微型交付边界，核对被测文件对应当前框架版本。需要同步时只修改已明确授权的具体文件，保留机器配置及无关内容。
- **核对环境**：在目标项目读取其 `docs/methodology-config.json`，复用仍有效的实际准备；已有准备失效或无法确认时，执行 `yaya/tools/checks/check-project-environment.py --require-ready` 并读取真实结果。

**S2｜完成微型任务**

- **需求与实施**：只在外部验证项目中使用 `product-author` 对照已有 GDD 预拆分当前约定范围，再细化已轮到的微型 Product；`feature-plan` 覆盖其完整必要范围，再由 `feature-execute` 完成实际实现和适用检查。
- **计划与自动测试**：项目 Python 调用 `yaya/tools/checks/check-feature-list.py` 核对计划，自动测试通过 `yaya/tools/testing/run-gdunit-tests.py --feature <实际ID> --scope <实际范围>` 执行；保留所有原始结果。
- **人工义务与执行边界**：人工义务到真实体验交接点停止，不伪造接受；框架仓库不激活这些项目流程。

**S3｜回报流程问题**

区分原框架、使用误解和环境问题，写明实际命令、失败、停止位置及最小改进建议。未执行的分支、创建器、GDD 初始化、续接和迁移检查列为未覆盖。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 项目路径、GDD 入口和被测文件版本的核对结果 |
| S2 | 各阶段的实际命令与原始输出，包括 `check-feature-list` 和 gdUnit 运行 |
| S3 | 报告已交付，含逐阶段结果和未覆盖清单 |

## 资源与文件影响

- **只读对象**：框架仓库及未选作验证目标的其他游戏项目只读。
- **可写对象**：指定外部验证项目获准维护相关 Product、计划、业务实现、测试、运行报告、必要进度记录和本地提交。
- **Git 责任**：保留已有仓库和历史，来源、规划及交付提交遵循该项目实际规则。
- **验证保护**：不得修改从框架复制来的规则、Skill 或公共工具来使验证通过；原始证据保留。
- **当次报告**：要求保存时放在本仓库 `tmp/reports/<任务>/`，`tmp/` 不进 Git，用完删除。

## 阻塞、异常与范围变化

缺少真实 GDD、指定项目不可访问或被测版本无法核实时说明缺口并停止依赖工作，不现场生成占位设计。证据不可用时收窄结论；不把静态推演写成真实运行。

## 完成状态与验证标准

指定微型流程的实际证据报告完成；未获得人工验收的工作如实保留。

## 流程关联与衔接关系

项目 Skill 在目标自己的 `.agents/skills/` 使用；源契约可核对 [product-author](../../../../../project-source/skills/product-author/SKILL.md)、[feature-plan](../../../../../project-source/skills/feature-plan/SKILL.md)和 [feature-execute](../../../../../project-source/skills/feature-execute/SKILL.md)。
