# 关系图工具

[框架入口](../../README.md#维护命令)

本目录保存文档系统关系图的覆盖检查脚本，以及两张图共用的连线穿过节点检查；开发场景图的名称与链接检查以提示词库为输入，放在[提示词与场景工具](../../prompt-scenarios/tools/README.md)。命令在仓库根目录、使用已确认的 Python 3.12+ 运行；`-B` 禁止生成字节码缓存，参数细节以 `--help` 为准。

## 检查文档图覆盖

仅在用户需要找出未纳入文档系统图的文件时运行：

```powershell
python -B framework/relationship-maps/tools/check_document_graph_coverage.py
```

命令只读现有文件、复制清单和文档图，不更新图、不写报告、不生成项目。默认扫描框架与分发源的 Markdown、Markdown/JSON 文档模板，以及文档目录、提示词库、复制清单和项目环境配置中的 JSON，包含 README 与索引页；第三方插件、缓存、个人图谱次数、临时文档、代码配置和素材数据不在范围内。项目区核对分发源对应的目标路径，不扫描已有外部项目；尚未创建的可选产物不会被当作缺失。

- **参数**：`--json` 列出每个文件命中的节点 ID；`--root` 指定框架仓库；`--graph` 指定图文件，相对路径以该仓库为基准。
- **退出码**：`0` 全部覆盖；`1` 存在未覆盖文件；`2` 图或路径登记无法读取、格式错误。
- **结果含义**：覆盖只表示路径归入了某个职责节点，正文是否被使用、引用是否正确仍须另行判断。它与[检查孤立文档](../../maintenance/tools/README.md#检查孤立文档)中的扫描回答不同问题。

## 检查连线穿过节点

新增或移动连线、折点或节点后运行，找出从别的节点上穿过的连线：

```powershell
python -B framework/relationship-maps/tools/check_graph_edge_crossings.py
```

命令只读图文件，默认检查开发场景图和文档系统图。每条连线按“起点端口 → 各折点 → 终点端口”连成折线，水平或竖直的线段（误差 1 像素内）穿进别的节点矩形内部才算穿过，贴着边框走不算。连线两端的节点和 `legend-`、`caption-` 阅读辅助不参与比较。

- **参数**：`--graph` 指定图文件，可重复，相对路径以仓库根目录为基准；`--json` 输出每处穿过的连线、节点和线段坐标。
- **退出码**：`0` 没有穿过；`1` 有连线穿过节点；`2` 图文件读不出来、同一对象里有重复键（例如合并冲突解决后留下两个 `target`），或连线指向不存在的节点、端口。
- **查不到的情况**：两端既不同行也不同列的线段由查看器自己补拐点，脚本不知道实际走法，只在结果里计数。连线之间挤在一起、标签重叠也不检查，这些仍要在查看器里看。
