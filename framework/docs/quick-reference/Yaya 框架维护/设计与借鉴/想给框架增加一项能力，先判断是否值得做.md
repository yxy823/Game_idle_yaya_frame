# 想给框架增加一项能力，先判断是否值得做

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

想给框架增加一项能力，先判断是否值得做。需要的材料：

- **问题与发生情况：** 实际问题、发生频率。
- **改善目标与影响：** 期望改善、受影响范围。

## 前置条件与适用范围

尚未选定实施方案，本次只需必要性与落点建议。

## 执行步骤

使用[集中提示词库](<../../../../prompts.json>)中的“Yaya 框架维护 → 设计与借鉴 → 想给框架增加一项能力，先判断是否值得做”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页由当前 Agent 使用现有规则和工具处理；需要独立审核的步骤明确交给独立实例。

**S1｜核对已有能力**

当前 Agent 阅读受影响实现和调用者，确认现有命令、说明或人工操作能否满足问题。

**S2｜比较最小方案**

比较不新增、说明改进、复用或合并、最小新增的成本，并给推荐落点与验证方法。

## 资源与文件影响

相关 framework/ 和 project-source/ 文件只读；建议在对话交付。

## 阻塞、异常与范围变化

缺少复现场景时说明证据不足，不凭外部能力数量推定必须新增。

## 完成状态与验证标准

必要性、推荐方案、影响文件及验证建议明确；没有修改维护源。
