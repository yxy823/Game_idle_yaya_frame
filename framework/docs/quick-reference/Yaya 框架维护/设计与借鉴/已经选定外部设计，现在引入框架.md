# 已经选定外部设计，现在引入框架

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

已经选定外部设计，现在引入框架。需要的材料：选中设计和出处、确定方案、许可信息、获准写入与验证范围。

## 前置条件与适用范围

已确定具体借鉴项，本次落地其最小实现。

## 执行步骤

使用[集中提示词库](<../../../../prompts.json>)中的“Yaya 框架维护 → 设计与借鉴 → 已经选定外部设计，现在引入框架”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页由当前 Agent 使用现有规则和工具处理；需要独立审核的步骤明确交给独立实例。

**S1｜核对出处与契约**

当前 Agent 读取选中版本与当前调用方；直接复用代码前核对许可和所需声明。

**S2｜实施所选设计**

按现有职责最小适配，保留必要出处声明，排除外部历史、缓存和无关业务。

**S3｜验证关联入口**

同步受影响配置、复制映射、说明与回归，按根规则验证并提交。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 引入来源与许可边界明确 |
| S2 | 只有选中能力进入维护源 |
| S3 | 来源、实现及调用相互一致 |

## 资源与文件影响

选中维护源与必要许可声明会修改；外部仓库本身只读。

## 阻塞、异常与范围变化

许可不明时暂停代码搬入；已授权的自主重新实现按具体范围继续。

## 完成状态与验证标准

所选设计已在当前框架适配并通过必要检查，未引入无关体系。
