# 框架刚改完，在指定外部项目验证工具行为

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

框架刚改完，在指定外部项目验证工具行为。需要的材料：

- **被测对象与位置：** 被测变更、外部项目绝对路径。
- **运行与同步范围：** 运行范围、允许同步的文件。

## 前置条件与适用范围

外部验证项目已经存在且获准使用。

## 执行步骤

使用[集中提示词库](<../../../../yaya-maintenance-prompts.json>)中的“Yaya 框架维护 → 维护与复盘 → 框架刚改完，在指定外部项目验证工具行为”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页由当前 Agent 使用现有规则和工具处理；需要独立审核的步骤明确交给独立实例。

**S1｜核对被测版本**

当前 Agent 比较项目中的被测文件与维护源，只同步本次获准文件，保留机器配置与无关业务。

**S2｜执行针对性验证**

使用项目实际配置运行适用工具或测试，保留命令、版本、原始结果及失败。

**S3｜报告覆盖与限制**

区分工具回归、真实引擎和人工体验；缺少项目时转准备场景，不擅建新项目。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 运行对象确实对应本次修改 |
| S2 | 工具行为具有当前运行证据 |
| S3 | 结论与实际执行范围对应 |

## 资源与文件影响

指定项目内被测文件与运行产物可能改变；框架其他内容不随验证修改。

## 阻塞、异常与范围变化

权限、环境或版本不符时保留现场与具体阻塞；旧通过不适用于新版本。

## 完成状态与验证标准

被授权的工具行为已实际验证，原始证据和未执行项可定位。
