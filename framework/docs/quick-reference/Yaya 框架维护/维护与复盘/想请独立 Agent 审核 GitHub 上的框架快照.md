# 想请独立 Agent 审核 GitHub 上的框架快照

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

想请独立 Agent 审核 GitHub 上的框架快照。需要的材料：

- **审核对象与范围：** 检查范围、版本或原始材料。
- **交付位置：** 报告输出位置。

## 前置条件与适用范围

指定 GitHub 仓库与分支或提交；只读取远端快照。

## 执行步骤

使用[集中提示词库](<../../../../prompts.json>)中的“Yaya 框架维护 → 维护与复盘 → 想请独立 Agent 审核 GitHub 上的框架快照”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页由当前 Agent 使用现有规则和工具处理；需要独立审核的步骤明确交给独立实例。

**S1｜固定远端版本**

独立审核 Agent 将指定分支解析到完整 SHA，以该 SHA 读取目录和文件永久链接。

**S2｜检查快照契约**

读取实际正文与实现，对照框架承诺追查复制、规则、工具和完成条件；标明截断和不可读部分。

**S3｜输出中文报告**

给出问题、依据、影响、最小建议和未运行项，保存为获准报告。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 整份报告使用同一快照 |
| S2 | 每项判断可回到版本证据 |
| S3 | 快照审核报告可独立复核 |

## 资源与文件影响

被审源与原始证据只读；只写获准报告。

## 阻塞、异常与范围变化

证据不可用时收窄结论；不把静态推演写成真实运行。

## 完成状态与验证标准

同一 SHA 的独立报告已交付，没有执行被审代码或推断本地状态。
