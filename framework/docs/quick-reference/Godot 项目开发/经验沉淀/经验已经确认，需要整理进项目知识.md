## 执行步骤

使用[集中提示词库](<../../../../prompts.json>)中的“Godot 项目开发 → 经验沉淀 → 经验已经确认，需要整理进项目知识”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页由当前 Agent 使用现有规则和工具处理；需要独立审核的步骤明确交给独立实例。

**S1｜核对知识归属**

当前 Agent 先读最近主题索引和已有条目，判断更新或合并到唯一正文。

**S2｜整理可复用解释**

维护 docs/knowledge/ 的合适条目及最近索引，写场景、做法、原因、边界与原始依据链接。

**S3｜交付文档变化**

检查链接和语义，按项目规则提交；局部事件经过仍留原 notes，不复制整段历史。
