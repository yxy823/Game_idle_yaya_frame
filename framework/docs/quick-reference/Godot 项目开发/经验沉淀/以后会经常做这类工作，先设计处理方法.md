# 以后会经常做这类工作，先设计处理方法

[返回场景索引](../../scenario-index.md)

## 触发场景与使用时机

为预计经常进行、但尚没有足够历史实例的一类工作设计处理方法。例如，预计今后经常比较资源接入方案，想先讲清每次需要什么输入、交付怎样的比较结果。

## 前置条件与适用范围

在实际 Godot 项目处理。只设计指定未来工作的一次完整处理，不要求先提供失败历史，不扩展成全项目流程重构。沿用项目已有真实 GDD 的前提；本入口不初始化游戏设计。本次只读分析，结论留在对话。

## 执行步骤

使用[集中提示词库](../../../../prompts.json)中的“Godot 项目开发 → 经验沉淀 → 以后会经常做这类工作，先设计处理方法”。提供预计经常进行的工作、何时发生、预期输入和产出、使用限制以及已有决定。已有对话直接补齐必要材料，不必重发模板。当前 Agent 使用项目自己的 `loop-me-godot` Skill；[源码入口](../../../../../project-source/skills/loop-me-godot/SKILL.md) 仅供核对。

**S1｜明确预期工作的一次处理**

从预期情境确定触发、输入、独立判断、必要用户决定和出口；核对已有入口与权威文档，将事实、已决定内容和暂定假设分开。

**S2｜形成可复用的处理方案**

交付可审阅的处理方案、推荐入口和正文归属，说明哪些内容可沿用、哪些需要首次使用时核实及会影响采用的选择。必要选择成组说明推荐与影响，普通实现细节由 Agent 判断。

## 资源与文件影响

相关材料可按需只读查阅，包括文件与 Git 历史；不写知识、报告或流程文件，不执行项目运行或验证命令，不创建自动任务。

## 阻塞、异常与范围变化

缺少会改变方案的关键输入时，完成不依赖它的设计，保留具体未决选择。本场景不授予实施权限，后续明确授权由原有负责者承接。

## 完成状态与验证标准

预期工作的完整处理方法和关键假设已说明，采用前的实质选择明确；没有把设计方案当成已实施或已验证能力。用明确标注的预期情境静态推演正常处理与确有必要的中断情况，检查输入到产出是否完整；不编造历史频次、运行结果或节省时间。
