# 重构目标已经选定，现在调整结构并保持行为

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

重构目标已经选定，现在调整结构并保持行为。

需要的材料：

- 重构目标与原因：确定目标、当前痛点。
- 保持边界：不变契约与获准范围。

## 前置条件与适用范围

已有具体重构目标，不再在本入口筛选候选。

## 执行步骤

使用[集中提示词库](<../../../../godot-development-prompts.json>)中的“Godot 项目开发 → 修复与改进 → 重构目标已经选定，现在调整结构并保持行为”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页使用 [$engineering-change-plan](<../../../../../project-source/skills/engineering-change-plan/SKILL.md>)、[$feature-execute](<../../../../../project-source/skills/feature-execute/SKILL.md>)，具体执行者和切换位置见下文。

**S1｜建立重构任务**

当前 Agent 阅读实际实现与依赖，用 engineering-change-plan 的 refactor 模式明确不变 API 和行为、维护收益与回归范围，简述结构调整方案。

**S2｜实施结构调整**

当前 Agent 使用 feature-execute 核对现有行为证据，再完成最小结构改动。按共用工程规则控制影响，保持无需变化的依赖与代码风格，不顺带改玩法。

**S3｜验证不变契约**

当前 Agent 运行相称回归和支持的适用静态检查，检查最终差异与维护目标。交付说明关键文件、行为保持依据及实际维护收益，不能只凭测试通过判定重构有价值。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 独立结构目标与 AC 清楚 |
| S2 | 结构改善未扩大行为范围 |
| S3 | 行为保持和目标改善均有依据 |

## 资源与文件影响

获准代码结构、必要测试和工程任务记录修改；GDD 设计和约定行为不变。

## 阻塞、异常与范围变化

发现必须改变行为才能继续时明确范围变化，不把它藏进重构。

## 完成状态与验证标准

结构目标达成且约定行为保持，适用验证与交付完成。
