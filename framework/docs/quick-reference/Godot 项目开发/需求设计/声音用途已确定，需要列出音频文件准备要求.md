# 声音用途已确定，需要列出音频文件准备要求

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

声音用途已确定，需要列出音频文件准备要求。

需要的材料：

- 声音用途与触发：声音用途、播放事件。
- 方向与准备范围：声音方向和准备范围。

## 前置条件与适用范围

需要确定文件规格，不制作文件也不接入播放。

## 执行步骤

使用[集中提示词库](<../../../../godot-development-prompts.json>)中的“Godot 项目开发 → 需求设计 → 声音用途已确定，需要列出音频文件准备要求”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页使用 [$design-audio-asset-spec](<../../../../../project-source/skills/design-audio-asset-spec/SKILL.md>)，具体执行者和切换位置见下文。

**S1｜核对声音用途**

当前 Agent 使用 design-audio-asset-spec 读取具体触发、循环与重要程度及共享方向。

**S2｜写明交付规格**

在所属表现方案、界面或共享声音设计章节写时长、循环、格式、声道、响度与变体等适用要求，记录准备状态、来源和目标位置，指出实际试听缺口。

**S3｜核对唯一条目**

任务及各消费位置引用所属章节，避免另建资源清单或复制音频要求。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 文件要求有明确消费目标 |
| S2 | 准备者能按规格提供文件 |
| S3 | 文件要求与任务集合没有重复维护 |

## 资源与文件影响

所属表现方案、UI 或共享声音设计中的音频资源章节修改；共用方向保持唯一引用。

## 阻塞、异常与范围变化

方向或触发语义未定时先补齐决定，不能凭占位音频确认最终听感。

## 完成状态与验证标准

音频准备要求及接收检查依据明确，文件制作与播放尚未实施。
