需要的材料：

- 声音用途与体验：声音角色、目标体验。
- 参考与约束：参考与播放约束。

## 前置条件与适用范围

## 执行步骤

使用[集中提示词库](<../../../../prompts.json>)中的“Godot 项目开发 → 需求设计 → 当前模块的声音风格不明确，需要定下来”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页使用 [$design-audio-direction](<../../../../../project-source/skills/design-audio-direction/SKILL.md>)，具体执行者和切换位置见下文。

**S1｜收集专业依据**

当前 Agent 使用 design-audio-direction 读取 GDD 已有设计、已确认行为与参考，区分偏好和必须满足的约束。

**S2｜确定当前方向**

围绕情绪、声音角色、优先级、重复疲劳和必要静默提出取舍，与用户确认影响结果的关键选择。

**S3｜维护唯一规范**

GDD 已有细节直接引用复用，将缺少的实施规格与专业决定写入 docs/audio/sound-bible.md，明确适用对象并核对已有消费者影响。
