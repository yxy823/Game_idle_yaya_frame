## 执行步骤

使用[集中提示词库](<../../../../prompts.json>)中的“Godot 项目开发 → 需求设计 → 玩家要做什么已确定，需要设计界面和交互”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页使用 [$design-ui-spec](<../../../../../project-source/skills/design-ui-spec/SKILL.md>)，具体执行者和切换位置见下文。

**S1｜拆解交互状态**

当前 Agent 用 design-ui-spec 核对入口、动作、可见反馈、错误和空状态。

**S2｜确定页面规格**

说明布局、信息层级、输入方式和状态转换，必要视觉未知先实验。

**S3｜保存规格引用**

直接维护 docs/ui/<interface>-design.md，Product 保留行为和链接。
