## 触发场景与使用时机

界面效果还没确定，先用真实素材试一下。

需要的材料：

- 视觉假设与样本：一个视觉假设、真实素材。
- 观察条件与边界：显示条件、预算与观察标准。

## 前置条件与适用范围

关键方案尚未确定；已授权一个有预算的视觉实验。

## 执行步骤

使用[集中提示词库](<../../../../prompts.json>)中的“Godot 项目开发 → 需求设计 → 界面效果还没确定，先用真实素材试一下”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页由当前 Agent 使用现有规则和工具处理；需要独立审核的步骤明确交给独立实例。

**S1｜限定视觉问题**

当前 Agent 使用 [prototype-godot](../../../../../project-source/skills/prototype-godot/SKILL.md)，确认要比较的尺寸、布局或色彩关系，沿已有原型约定限定一个问题。

**S2｜搭建可观察样本**

在获准独立场景用真实素材呈现目标显示条件，需要时使用既有资源工作台，不搭业务系统。

**S3｜记录观察和去向**

用户给出视觉反馈；Agent 记录结论、局限和实验文件保留或移除决定。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 实验不承担完整界面交付 |
| S2 | 用户可看到实际效果 |

## 资源与文件影响

只修改获准实验文件和必要报告；正式 Product 与 Feature 状态保持真实。

## 阻塞、异常与范围变化

达到预算、输入不可用或观察条件不足时停止实验并保留原始结果，不把未测内容写成通过。
