# 图片用途已确定，需要列出视觉文件准备要求

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

图片用途已确定，需要列出视觉文件准备要求。

需要的材料：

- 视觉用途：视觉对象、消费位置。
- 显示与方向要求：显示尺寸、共享方向。

## 前置条件与适用范围

需要确定图片等视觉资源的可交付规格。

## 执行步骤

使用[集中提示词库](<../../../../godot-development-prompts.json>)中的“Godot 项目开发 → 需求设计 → 图片用途已确定，需要列出视觉文件准备要求”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页使用 [$design-visual-asset-spec](<../../../../../project-source/skills/design-visual-asset-spec/SKILL.md>)，具体执行者和切换位置见下文。

**S1｜核对显示用途**

当前 Agent 使用 design-visual-asset-spec 确认对象身份、显示场景、密度及状态。

**S2｜形成文件要求**

写清尺寸、透明边缘、九宫格或切片等适用参数、命名和授权来源要求。

**S3｜保存唯一条目**

把方案专用资源写入所属表现方案，界面专用资源写入 UI 文档，共用资源写入共享视觉设计章节；记录准备状态、来源和目标位置，引用共享方向，不另建资源清单。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 资产需求由实际界面或游戏表现消费确定 |
| S2 | 文件准备与技术检查有依据 |
| S3 | 需求可定位且无多份冲突 |

## 资源与文件影响

所属表现方案、UI 或共享视觉设计的资源章节修改；本页不画图或导入。

## 阻塞、异常与范围变化

缺少实际显示尺寸时明确缺口，不随意定稿导入参数。

## 完成状态与验证标准

视觉文件要求清楚，可用于准备和接收检查。
