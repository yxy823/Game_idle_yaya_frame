# 场景文件及依赖已准备好，现在接入当前游戏

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

场景文件及依赖已准备好，现在接入当前游戏。

所需材料：

- 任务与消费位置：当前任务、实例位置与确认行为。
- 待接入资源：来源场景、依赖资源。

## 前置条件与适用范围

需要接入一份已有场景，目标消费和授权范围已确定。

## 执行步骤

使用[集中提示词库](../../../../prompts.json)中的“Godot 项目开发 → 资源、性能与数据 → 场景文件及依赖已准备好，现在接入当前游戏”。由当前 Agent 使用 [$content-asset-integration](../../../../../project-source/skills/content-asset-integration/SKILL.md)，运行修改与交付返回 [$feature-execute](../../../../../project-source/skills/feature-execute/SKILL.md)。

**S1｜核对接入契约**

当前 Agent 使用 content-asset-integration，读取场景、脚本、子资源及 UID/路径依赖，确认原场景的许可和所需配置，不把整个来源项目当依赖。

**S2｜完成资源接入**

只复制必要文件并在目标实例化，调整实际路径、信号和所属节点关系，保留项目既有配置。

**S3｜检查真实运行**

返回 feature-execute，实际加载目标与接入场景，检查初始化、重复实例和释放，记录可观察行为与用户体验缺口。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 输入和实际依赖明确 |
| S2 | 目标项目引用已建立 |
| S3 | 运行与体验结果如实记录 |

## 资源与文件影响

必要场景、依赖资源、目标实例与信号引用修改；不复制来源缓存、机器配置或无关 Autoload。

## 阻塞、异常与范围变化

资源缺失、依赖不明或要求冲突时保留缺口；不凭导入成功宣称功能或体验通过。

## 完成状态与验证标准

场景可在目标游戏加载和运行，必要依赖完整且不存在无关来源项目依赖。
