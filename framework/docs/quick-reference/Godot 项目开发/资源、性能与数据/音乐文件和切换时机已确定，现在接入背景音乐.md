# 音乐文件和切换时机已确定，现在接入背景音乐

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

音乐文件和切换时机已确定，现在接入背景音乐。所需材料：当前任务、确认音乐、循环点、切换事件和混音要求。

## 前置条件与适用范围

新增背景音乐的文件和状态切换已经确认。

## 执行步骤

使用[集中提示词库](../../../../prompts.json)中的“Godot 项目开发 → 资源、性能与数据 → 音乐文件和切换时机已确定，现在接入背景音乐”。由当前 Agent 使用 [$content-asset-integration](../../../../../project-source/skills/content-asset-integration/SKILL.md)，运行修改与交付返回 [$feature-execute](../../../../../project-source/skills/feature-execute/SKILL.md)。

**S1｜核对接入契约**

当前 Agent 使用 content-asset-integration，核对音频格式、循环接缝、各状态对应曲目与有效声音规范，读取真实文件。

**S2｜完成资源接入**

在当前任务中接入播放、暂停、停止和状态过渡，避免场景切换重复创建播放器或叠放。

**S3｜检查真实运行**

返回 feature-execute，真实运行目标状态及切换，试听循环接缝、过渡、混音和停止，记录用户实际反馈。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 输入和实际依赖明确 |
| S2 | 目标项目引用已建立 |
| S3 | 运行与体验结果如实记录 |

## 资源与文件影响

新增音乐资源、播放器及状态引用；同一清单记录实际去向，原声音规格不改。

## 阻塞、异常与范围变化

资源缺失、依赖不明或要求冲突时保留缺口；不凭导入成功宣称功能或体验通过。

## 完成状态与验证标准

背景音乐在确认状态正确播放与切换，实际试听及必要验证有结果。
