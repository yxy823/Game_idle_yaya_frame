# 存档结构需要修改，旧数据不需要继续使用

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

存档结构需要修改，旧数据不需要继续使用。

需要的材料：

- 任务与结构：所属任务、当前与目标结构。
- 旧数据决定：不保留旧数据的明确决定。

## 前置条件与适用范围

数据变化已明确且由正式任务承接；玩家含义变化先由 Product 确认。

## 执行步骤

使用[集中提示词库](<../../../../prompts.json>)中的“Godot 项目开发 → 资源、性能与数据 → 存档结构需要修改，旧数据不需要继续使用”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页使用 [$engineering-change-plan](<../../../../../project-source/skills/engineering-change-plan/SKILL.md>)、[$feature-execute](<../../../../../project-source/skills/feature-execute/SKILL.md>)，具体执行者和切换位置见下文。

**S1｜确认数据含义**

当前 Agent 核对新结构与正式玩家需求，确认没有旧数据继续使用义务。

**S2｜修改当前读写**

所属 maintenance 或 Feature 完成最小字段与读写调整，不增加版本迁移层。

**S3｜验证新数据**

在测试数据范围核对默认值、往返读写和失败行为，不操作用户唯一存档。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 无需历史兼容的前提明确 |
| S2 | 新格式可写可读 |
| S3 | 新结构行为符合要求 |

## 资源与文件影响

获准数据实现和样本副本修改；真实唯一存档与未授权个人数据不动。

## 阻塞、异常与范围变化

无法无损转换或含义未定时停止依赖部分，不能静默丢弃字段或扩大数据访问。

## 完成状态与验证标准

新结构读写和失败行为验证完成，没有多余历史兼容层。
