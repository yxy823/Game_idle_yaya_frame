# 翻译已接入，需要独立检查语言与显示

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

翻译已接入，需要独立检查语言与显示。

需要的材料：

- 版本与语言要求：语言版本、本地化规格。
- 实际显示与语境：实际界面与目标语境。

## 前置条件与适用范围

成果版本和权威要求明确，本次明确启用该领域独立审核。

## 执行步骤

使用[集中提示词库](<../../../../godot-development-prompts.json>)中的“Godot 项目开发 → 验证与收尾 → 翻译已接入，需要独立检查语言与显示”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页使用 [$review-localization](<../../../../../project-source/skills/review-localization/SKILL.md>)，具体执行者和切换位置见下文。

**S1｜交接审核材料**

主 Agent 向新上下文 independent-reviewer 交范围、版本、来源、原始证据与验证权限，作者总结仅作待核实陈述。

**S2｜按领域检查**

独立 Agent 使用 review-localization 核对含义、术语、字体、截断和回退，需要结论时取得实际显示与具备依据的语言判断。

**S3｜交付审核报告**

给出语言质量与显示限制；成果、原件和验收只读，获准验证缓存和数据隔离。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 独立性与权限已核实 |
| S2 | 判断有领域适用证据 |
| S3 | 报告不代替用户人工验收 |

## 资源与文件影响

被审成果、原证据和验收记录只读；只写获准报告与隔离验证产物。

## 阻塞、异常与范围变化

- 证据不足：无法取得必要真实证据时明确未验证，不能以作者声明代替。
- 独立性不足：无法独立时说明限制。

## 完成状态与验证标准

该范围的独立报告已交付，语言质量与显示限制明确，没有修复被审成果。
