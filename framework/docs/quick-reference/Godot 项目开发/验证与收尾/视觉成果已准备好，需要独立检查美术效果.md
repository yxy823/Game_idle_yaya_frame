# 视觉成果已准备好，需要独立检查美术效果

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

视觉成果已准备好，需要独立检查美术效果。

需要的材料：

- 版本与美术要求：视觉版本、美术方向。
- 实际显示材料：显示条件和实际画面。

## 前置条件与适用范围

成果版本和权威要求明确，本次明确启用该领域独立审核。

## 执行步骤

使用[集中提示词库](<../../../../prompts.json>)中的“Godot 项目开发 → 验证与收尾 → 视觉成果已准备好，需要独立检查美术效果”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页使用 [$review-art](<../../../../../project-source/skills/review-art/SKILL.md>)，具体执行者和切换位置见下文。

**S1｜交接审核材料**

主 Agent 向新上下文 independent-reviewer 交范围、版本、来源、原始证据与验证权限，作者总结仅作待核实陈述。

**S2｜按领域检查**

独立 Agent 使用 review-art 核对信息层级、视觉一致性与目标场景可读性，需要结论时取得指定显示条件下的实际画面。

**S3｜交付审核报告**

给出美术符合性和未观察部分；成果、原件和验收只读，获准验证缓存和数据隔离。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 独立性与权限已核实 |
| S2 | 判断有领域适用证据 |
| S3 | 报告不代替用户人工验收 |

## 资源与文件影响

被审成果、原证据和验收记录只读；只写获准报告与隔离验证产物。

## 阻塞、异常与范围变化

- 证据不足：无法取得必要真实证据时明确未验证，不能以作者声明代替。
- 独立性不足：无法独立时说明限制。

## 完成状态与验证标准

该范围的独立报告已交付，美术符合性和未观察部分明确，没有修复被审成果。
