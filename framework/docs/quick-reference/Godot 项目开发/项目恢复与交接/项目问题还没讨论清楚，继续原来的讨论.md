# 项目问题还没讨论清楚，继续原来的讨论

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

项目问题还没讨论清楚，继续原来的讨论。准备材料：

- **已有上下文**：原问题与已确认决定。
- **本次讨论**：剩余疑问和新增信息。

## 前置条件与适用范围

原工作仅为讨论，尚未形成需要的决定；用户继续讨论，不授权落盘或实现。

## 执行步骤

使用[集中提示词库](../../../../prompts.json)中的“Godot 项目开发 → 项目恢复与交接 → 项目问题还没讨论清楚，继续原来的讨论”。已有对话补齐实际材料即可，续接不重新索取已经存在的授权。游戏设计沿用 [design-gdd](../../../../../project-source/skills/design-gdd/SKILL.md)，交付取舍沿用 product-spec-elicitor；其他单个问题使用 [$project-grill-me](../../../../../project-source/skills/project-grill-me/SKILL.md)，原讨论涉及多项相互依赖的未知时沿用 [wayfinder-godot](../../../../../project-source/skills/wayfinder-godot/SKILL.md)。

**S1｜恢复已有决定**

当前 Agent 沿用原讨论方法，核对原问题、相关事实、用户明确选择及尚未解决的依赖，不重复询问已回答问题。

**S2｜集中讨论剩余取舍**

将同类关键问题一起提出推荐与影响；多项问题相互依赖时，先处理已有前提的疑问并继续获准的只读调查。新材料只改变对应部分，不重新开始整套访谈，也不因续接默认创建原型或 worktree。

**S3｜总结当前结论**

交付已确定结论、仍缺的决定和必要下一步；不写 Product 或自动调用实现 Skill。

## 步骤产出与状态变化

| 步骤 | 继续条件 |
| --- | --- |
| S1 | 已定和待定分别明确 |
| S2 | 用户只需判断实质未决项 |
| S3 | 讨论出口与实施授权分开 |

## 资源与文件影响

项目材料只读，结论在对话；不因续接生成术语文档、Product 或 Feature。

## 阻塞、异常与范围变化

发现原摘要与真实决定冲突时核对具体依据，不能把 Agent 建议当用户选择。

## 完成状态与验证标准

原讨论问题得到当前结论或明确剩余取舍，没有重复已完成澄清。
