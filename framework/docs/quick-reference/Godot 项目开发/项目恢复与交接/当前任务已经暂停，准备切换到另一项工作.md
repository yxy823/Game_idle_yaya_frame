# 当前任务已经暂停，准备切换到另一项工作

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

当前任务已经暂停，准备切换到另一项工作。需要的材料：已暂停任务、目标任务和切换授权。

## 前置条件与适用范围

单人同一项目目录切换，原任务停点已经记录。

## 执行步骤

使用[集中提示词库](<../../../../prompts.json>)中的“Godot 项目开发 → 项目恢复与交接 → 当前任务已经暂停，准备切换到另一项工作”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页由当前 Agent 使用现有规则和工具处理；需要独立审核的步骤明确交给独立实例。

**S1｜核对暂停记录**

当前 Agent 确认原任务的未完成文件、运行和证据已记录，不把它标完成。

**S2｜核对目标前置**

读取目标任务依赖、范围和实际相关差异，确认不会覆盖现有成果。

**S3｜进入目标工作**

使用目标所属 Skill 在其已授权范围执行；原任务继续保持暂停记录。

## 步骤产出与状态变化

| 步骤 | 可继续的依据 |
| --- | --- |
| S1 | 原工作可恢复 |
| S2 | 两项任务的具体修改可安全区分 |
| S3 | 切换不是重建工作区 |

## 资源与文件影响

更新必要 Progress 并在目标授权范围写入；不新增分支隔离或 worktree 流程。

## 阻塞、异常与范围变化

确实重叠的编辑或提交边界无法分离时先解决具体冲突，不要求整个目录干净。

## 完成状态与验证标准

目标工作已从正确入口开始，原任务现场和恢复信息保留。

## 流程关联与衔接关系

依据：[项目路由依据](<../../../../../project-source/methodology/00-overview.md>)。本页达到出口后，仍已明确授权的后续工作按其所属场景继续；准备、诊断、规划或记录完成不替代 Feature 的正式完成。
