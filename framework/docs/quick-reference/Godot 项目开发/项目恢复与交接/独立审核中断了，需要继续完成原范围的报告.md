# 独立审核中断了，需要继续完成原范围的报告

[返回场景索引](../../scenario-index.md) · [执行步骤](#执行步骤) · [完成标准](#完成状态与验证标准)

## 触发场景与使用时机

独立审核中断了，需要继续完成原范围的报告。准备材料：

- **审核范围**：原审核目标与范围、固定版本。
- **已有成果**：已有报告与已核实证据。
- **验证边界**：验证权限。

## 前置条件与适用范围

原任务是未完成的独立审核，没有开发 Feature；本次继续原审核范围。

## 执行步骤

使用[集中提示词库](../../../../prompts.json)中的“Godot 项目开发 → 项目恢复与交接 → 独立审核中断了，需要继续完成原范围的报告”。已有对话补齐实际材料即可，续接不重新索取已经存在的授权。 本页的执行者、角色和具体方法见各步骤；没有专用 Skill 时使用当前 Agent 与现有职责契约。

**S1｜恢复独立上下文**

协调 Agent 复用仍可用的独立审核实例，或向新的独立实例交接原范围、版本、实际原件和权限；作者摘要不能替代原件。

**S2｜补审缺失范围**

独立 Agent 按以下范围补审：

- **覆盖与证据**：核实原结论仍对应当前版本，只复用仍有效且可追查的检查；补读未审或已变化部分。
- **审核方法**：代码用 review-code，专业对象沿原选定 review 方法。

**S3｜完成同一报告**

合并同因问题，标明版本变化、旧结论适用范围和未验证项；仅写获准原报告，不实施修复。

## 步骤产出与状态变化

| 步骤 | 继续条件 |
| --- | --- |
| S1 | 独立性与被审基线明确 |
| S2 | 每项覆盖有实际审核依据 |
| S3 | 报告没有把未读内容默认为通过 |

## 资源与文件影响

被审内容、原证据、验收记录只读；仅更新获准审核报告，验证仍限制在原权限和隔离范围。

## 阻塞、异常与范围变化

旧基线不可读或无法保持独立时说明具体限制；不能由作者自查补成独立通过。

## 完成状态与验证标准

原范围的独立报告已补足实际覆盖和限制；审核建议没有被自动实施。
