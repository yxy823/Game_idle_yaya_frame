## 执行步骤

使用[集中提示词库](<../../../../prompts.json>)中的“Godot 项目开发 → 日常开发 → Feature 已规划并可开始，现在实施这一项”。填入上述材料；已有对话直接补齐输入，不必重发入口。本页使用 [$feature-execute](<../../../../../project-source/skills/feature-execute/SKILL.md>)，具体执行者和切换位置见下文。

**S1｜确认开工任务**

当前 Agent 用 feature-execute 核对任务、依赖、来源、AC 和实际 Git 现场。

将 AC 对应到当前实现、直接消费者和验证义务，简述必要修改范围；复用仍有效的计划，不新增批准步骤。

**S2｜完成实现与验证**

当前 Agent 按现有执行规范完成最小完整实现，保持无需变化的 API、依赖与代码风格。完成相关测试及项目支持的适用静态检查，复用有效证据；独立评审只按用户明确请求启用。

**S3｜取得接受并收尾**

人工义务交用户真实体验。当前 Agent 检查最终差异，说明关键文件、实现理由、验证结果及具体风险，满足完成条件后记录和本地提交；按既有后续授权衔接。
