本目录面向修改框架源材料、复制工具、提示词及文档的维护者，保存维护准则和工具说明。具体维护场景按[场景编写要求](../quick-reference/README.md)迁入 `Yaya 框架维护` Project，游戏开发场景归另一个 Project；从[项目文档入口](../README.md)选择所需资料。

| 当前需要 | 入口 |
| --- | --- |
| 判断材料归属、同步说明、选择验证、复核反馈与继续维护 | [修改空白项目与同步使用说明](updating-the-blank-project.md) |
| 新增、调整或审核 Skill、脚本、提示词和场景的职责 | [职责设计准则](../../review/baselines/skill-script-prompt-design.md) |
| 区分源材料检查、工具回归、真实引擎运行与流程抽样 | [框架的复制与运行验证](validating-framework.md) |
| 查维护命令与集中提示词 | [维护工具](../../README.md) |
| 查尚需推进的工作 | [框架待办](../../progress.md) |
| 拆分旧专题与原场景检查单 | [迁移原材料](migration-source/README.md)，集中保存原正文及迁移边界 |

当前文档重构先交付整体目录和八篇场景样稿，讨论后再全量迁移。HTML 阅读版已暂缓，构建工具保留，恢复条件见[阅读版说明](updating-the-blank-project.md#html-阅读版暂缓)。本目录不进入项目复制清单。
