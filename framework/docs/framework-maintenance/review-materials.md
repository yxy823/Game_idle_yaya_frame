# 框架复盘材料

这里保存持续使用的职责准则，不进入生成项目。

| 入口 | 用途 |
| --- | --- |
| [根规则的核心原则](../../../AGENTS.md#核心决策原则) | 总体设计取舍与最小完整修改 |
| [职责设计准则](baselines/skill-script-prompt-design.md) | 文档固定归属、文本、Skill、脚本与提示词的职责判断 |
| [场景范围与责任](baselines/scenario-coverage.md) | 当前支持范围；具体入口由场景索引维护 |

审核默认在对话中交付。明确要求保存或当前任务确实需要留存的当次报告，统一放在仓库根目录的 `tmp/reports/<任务>/`，可继续按专题或检查轮次分层；注明被审版本、范围、实际证据和未验证项。其他临时文档按[根规则](../../../AGENTS.md#文件命名与修改)放在 `tmp/`，不得混入正式文档目录。

当次用途结束后删除报告及失效导航。需要长期保留的结论写回职责所属正式文档，由 Git 保存历史；`tmp/` 默认不纳入 Git。仍有待办时，只在[框架待办](../../progress.md)保留继续工作需要的事实与入口；确实仍需整份报告时，保留到该用途结束，不建立永久报告目录清单。旧报告不证明当前版本通过，也不授予修改权限。
