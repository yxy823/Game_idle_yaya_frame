## 怎样处理这些材料

先讨论八篇场景样稿，再按段落用途拆分：概念、配置和工具用法进入操作手册；所有具体情境的处理进入场景速查手册；框架源码维护留在维护目录。不要把整篇混合专题直接复制到新手册。

迁移时与已有页面合并同用途正文，核对真实规范、Skill、角色和提示词入口，并修正全部引用。某篇的有效内容全部迁走且引用清理完成后，删除该原材料；不保留长期双份教程。

待迁移材料只修正必要事实和失效引用，不继续扩写第二套新场景。迁移待办统一记在[框架待办](../../../progress.md)，本页只维护材料索引与处理边界。
