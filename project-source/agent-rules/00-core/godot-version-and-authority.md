# Godot 版本与依据

- 目标版本是 Godot 4.7，使用的可执行文件记录在 `docs/methodology-config.json`。不为简化任务修改目标版本、可执行文件、渲染器或升级状态；次版本或补丁版本升级按迁移处理。
- API 和引擎行为以 Godot 4.7 的类参考和文档为准。`/latest/` 文档、Godot 3.x 或其他版本的示例、博客、论坛和第三方项目只作线索，写进代码或规则前对照 4.7 核实。第三方插件按项目实际安装的版本查文档。
- 正确性依赖一个不确定的版本事实时，用 4.7 类参考、引擎源码或最小复现核实，不靠猜。文档与实际运行不一致时，先确认确切版本并做最小复现，再判断是引擎缺陷、文档缺陷、配置问题还是项目误用。
- 针对引擎缺陷的变通做法集中在一处，注释写明适用的版本和条件；可行时加回归测试。
