# 导出资源与过滤器

导出的资源选择和过滤器决定生产包的内容。编辑器中能看到或能读取的文件，不一定在包里。

## 打包

- 运行时通过 `FileAccess` 打开的非 Resource 原始文件（`.json`、`.csv`、`.txt` 等）不会自动导出。为它们配置明确的包含过滤器，或改成会被导出的 Resource。
- 名称以 `.` 开头的文件和目录不会被导出，包含过滤器也无法把它们加进包里。运行时需要的数据不放在以 `.` 开头的路径下。
- 只导出选定的场景或资源时，检查静态依赖分析发现不了的内容：`load()` 的动态路径、注册表和原始文件。
- 不要为缩小或清理包而使用宽泛、含义不清的包含或排除过滤器。

## 排除测试与编辑器插件

- 排除插件和资源前，先区分它是仅测试用、仅编辑器用还是运行时必需。`addons/` 不能整体排除。
- 生产导出要排除的测试目录、夹具和测试框架见[测试目录与导出](../70-tests/production-isolation.md#测试目录与导出)。
- 根目录的 `dev/` 只存放开发用的场景和脚本，生产导出整体排除。
- 排除文件不会删除对它的引用。排除后，确认生产配置和代码不依赖被排除的测试或编辑器文件；插件注册的 Autoload 见[编辑器插件](../40-project-config/autoloads-and-plugins.md#编辑器插件)。
