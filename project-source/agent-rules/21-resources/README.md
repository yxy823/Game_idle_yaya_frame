# 21 Resource（`.tres` / `Resource`）规则

按身份、生命周期、复用、编辑器所有权和 schema 语义拆分 Resource，不按行数拆分。

| 文档 | 何时阅读 |
| --- | --- |
| `roles-sharing-and-locality.md` | 选择 Resource 的角色、所有权、共享方式、变更通知或场景本地化 |
| `duplication-and-runtime-state.md` | 复制 Resource，或修改运行时状态和持久化资源图 |
| `schema-migration-and-serialization.md` | 修改 Resource 的字段、schema、构造、迁移或序列化 |
| `identity-paths-and-saving.md` | 修改身份、路径、保存或生成的 Resource |
| `validation.md` | 任何 Resource 修改：确定需要哪些验证 |
