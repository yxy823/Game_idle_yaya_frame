# 30 Shader Rules

Applies to hand-written `.gdshader` and `.gdshaderinc` for Godot 4.7.

There is no shader line-count limit. Split by independent visual responsibility,
reuse, and validation needs.

Read all concrete documents relevant to the shader:
`language-and-structure.md`, `uniforms-and-material-contracts.md`,
`coordinates-and-sampling.md`, `color-alpha-and-blending.md`,
`performance-and-stability.md`, `includes-and-reuse.md`, and `validation.md`.
