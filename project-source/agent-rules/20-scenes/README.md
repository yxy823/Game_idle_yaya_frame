# 20 Scene (`.tscn`) Rules

A `.tscn` file is serialized Godot scene state, not ordinary free-form text.

| Document | Read when |
| --- | --- |
| `structure-and-ownership.md` | Editing serialized scene state, node hierarchy or ownership |
| `instancing-inheritance-and-overrides.md` | Changing scene instances, inheritance, overrides or initialization order |
| `references-groups-and-order.md` | Changing resource IDs, NodePaths, groups, node names or ordering |
| `ui-and-scripts.md` | Changing UI layout/focus, script binding or signal connections |
| `validation.md` | Any scene change: determine its applicable validation |

There is no project rule that splits scenes by line count, node count, or tree depth alone.
