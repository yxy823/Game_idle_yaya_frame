# 源素材与派生素材

本页规定源素材、`.import`、导入缓存和导出包各自的权威性，以及变体、第三方素材许可证、`.gdignore` 与原始文件的要求。修改任何素材时读。

可编辑的源文件、`.import` 文件、`.godot/imported/` 缓存和导出包的权威性各不相同。`.import` 文件与 `.godot/imported/` 的归属见[生成文件与工具管理文件](../00-core/third-party-generated-and-temporary-files.md#生成文件与工具管理文件)。

## 源文件与生成内容

- 源文件是权威内容，`.godot/imported/` 是可重建的缓存。源文件和它的 `.import` 文件纳入版本控制，`.godot/` 不提交。
- 加载已导入的素材时，使用源文件的 `res://` 路径，不使用 `.godot/imported/` 中的路径。
- 可编辑母版（如 `.aseprite`、`.psd`、`.kra`）与交给 Godot 的运行时文件不同时，写明哪个是母版，以及从母版得到运行时文件的步骤或导出设置。
- 被 Git 忽略或只在本地的母版不等于缓存。删除前先确认它不是唯一的源。
- 在编辑器外修改素材后，先让 Godot 重新扫描和导入（见[重新导入](import-configuration.md#重新导入)），再相信编辑器或运行时看到的结果。

## 变体与副本

- 只有过滤、重复或材质参数不同时，在使用方设置这些参数，不复制源文件。
- 由脚本或工具生成的变体，与母版一样写明源文件和生成方法。

## 第三方素材的来源与许可证

- 每个第三方素材或素材包记录来源 URL、作者和许可证摘要，写在使用它的设计文档的资源条目中，位置按[资源需求与交接](../../methodology/11-specialist-workflows.md#资源需求与交接)确定。一个素材包写一次，不要求每个文件单独一份；素材包自带的许可证原件随素材保留，摘要链接它。
- “免费”“免版税”不是许可证结论。核实许可证对修改、再分发、商业使用和署名的要求。
- 许可条件不清楚时，不把素材用于要发布的版本。
- 只在许可证允许的范围内修改，保留要求的署名。

## 忽略目录与原始文件

- 注意：放有 `.gdignore` 的目录不会被导入，`load()` 和 ResourceLoader 也找不到其中的文件。不把运行时需要的素材、Resource，或测试运行器要加载的测试放进这类目录。
- `.gdignore` 控制 Godot 是否导入，`.gitignore` 控制 Git 是否跟踪，两者不能互相替代。
- 只为减少杂乱添加 `.gdignore` 前，先确认目录中没有运行时或导入依赖。
- 运行时通过 `FileAccess` 读取的原始文件不经过导入，是否进入导出包遵循导出配置规则中的[打包](../41-export-config/resources-and-filters.md#打包)。
- 导出后的游戏不通过列出目录中的源文件（如 `*.png`）发现素材：导出包中不含已导入的源文件，只有导入结果和 `.import` 重映射文件。需要素材清单时，在数据或 Resource 中显式登记。
