# 资源来源与许可证

第三方生产资源保持法律上可追溯，其修改和分发权利与预期用途一致。

## 来源

- **[必须]** 每个第三方生产资源或资源包都有可追溯的来源，以及许可证或授权许可的证据。
- **[必须]** 仅有“免费”或“免版税”不能作为许可证结论。核实修改、再分发、署名、商业使用以及其他适用条件的条款。
- **[必须]** 授权许可含糊时，在澄清之前不接受用于生产分发。
- **[必须]** 按合理的授权单位保存来源信息：按资源包、按单个资源，或放在集中清单中。不要机械地要求每张 PNG 配一个许可证文件。
- **[必须]** 只在许可证实际允许的范围内修改第三方资源，并保留要求的署名和来源声明。
