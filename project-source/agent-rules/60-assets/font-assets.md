# 字体素材

本页规定字体素材的选择、字形覆盖与回退。导入或修改字体，或调整文字的字形覆盖与回退时读。

## 字体选择

- 注意：商业字体，尤其是中文字体，可能把“在电脑上安装使用”和“嵌入软件或游戏发布”分开授权。能在本机装上、能做设计稿，不代表能打包进游戏。按[第三方素材的来源与许可证](source-and-derived-assets.md#第三方素材的来源与许可证)记录许可时，核实许可证是否允许嵌入和随游戏分发；SIL Open Font License（OFL）字体（例如思源黑体、Noto）允许随游戏分发。
- 一个逻辑字体只保留一个源文件，通过 Theme 或 Font Resource 复用。字号写在 Theme 或使用方上，不为不同字号复制字体文件。
- 可变字体的字重、宽度等轴用 `FontVariation` 设置，不复制源字体。
- 像素风格的游戏不一定要用位图字体。像素字体是否清晰，还取决于显示字号是否为设计尺寸的整数倍，以及 `antialiasing`、`hinting` 和使用方的过滤设置。
- 建议：需要实时缩放或大字号时再考虑 MSDF（`multichannel_signed_distance_field`）。开启后检查小字号的可读性。使用描边时，`msdf_pixel_range` 至少是最大描边尺寸的两倍；默认值 8 支持到 4。

## 字形覆盖与回退

- 注意：动态字体导入的 `allow_system_fallback` 默认开启。开发机上缺少的字形（例如中文）会由系统字体补上，换一台机器可能显示为方块。游戏使用的语言由项目内的字体或 `fallbacks` 列表覆盖，不依赖系统回退。
- 检查覆盖时，用游戏中实际出现的文本在界面里查看，包括中文、标点和数字，不只检查码位是否存在。
- `fallbacks` 列表按查找优先级排列，不按字母排序。
- 只预加载确实需要的字形范围，不预加载整个 Unicode。
- `FontVariation` 的模拟粗体（`variation_embolden`）和倾斜变换可能破坏字形设计，开启后目视检查。
