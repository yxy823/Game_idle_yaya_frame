# 分组与层

把分组名称和层索引当作稳定的行为命名空间。

## 分组

- **[必须]** 全局分组声明和场景中的分组成员共用同一个运行时分组命名空间。
- **[必须]** 自定义分组名称一旦被使用，就使用稳定的 `snake_case`。
- **[必须]** 全局分组声明不会把任何 Node 加入该分组。
- **[必须]** 不要依赖分组的遍历顺序，除非自己强制确定的顺序。

## 层

- **[必须]** 遵守 Godot 支持的层数量：物理层、导航层与渲染可见层的支持范围各不相同。
- **[必须]** 区分重命名层与改变层的用途或移动其位。不要为了好看而调整层的顺序。
- **[必须]** `collision_layer` 和 `collision_mask` 的语义分别迁移；两者不能互换。
- **[必须]** 不要到处散布没有解释的魔法层号。代码需要稳定的层语义时，使用项目自己的命名常量或配置。
- **[必须]** 物理层、导航层和渲染可见层的命名空间相互独立，即使它们使用相同的数字位。
- **[必须]** 清除层的显示名称不能证明该位未被使用。
