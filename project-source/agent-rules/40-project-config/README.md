# 40 Project Configuration Rules

Covers `project.godot` and ProjectSettings semantics. Build and distribution settings in `export_presets.cfg` belong to `41-export-config`.

| Document | Read when |
| --- | --- |
| `authoring-and-scope.md` | Any `project.godot` or ProjectSettings change: editing the file, effective values and feature-tag overrides, persistence, or deleting and renaming named settings |
| `application-startup.md` | Changing the main scene, the main loop type, the application name or the `user://` directory |
| `autoloads.md` | Adding, removing, reordering or changing Autoloads, or designing an event bus |
| `editor-plugins.md` | Enabling, disabling, adding or changing editor plugins |
| `groups-and-layers.md` | Declaring global groups, or naming or changing physics, navigation or render layers |
| `import-defaults.md` | Changing project-wide import defaults |
| `input-map.md` | Adding, changing or removing Input Actions, bindings, deadzones or rebinding, or reading Input Actions from editor code |
| `shader-globals.md` | Declaring or changing global shader uniforms or `ShaderGlobalsOverride` use |
| `subsystem-settings.md` | Changing audio, physics, localization, renderer, viewport, stretch, window or HDR settings |
| `validation.md` | Any project configuration change: determine its applicable validation |
