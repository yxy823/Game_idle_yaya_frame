# Script-IDE 的 Yaya 补丁

上游版本为 Maran23/script-ide `2.2.5`。
固定源码为 `11784e8dfef200116a1c8fb500f0188868e6bed6`。
`plugin.cfg` 保留上游版本号，本文件说明额外的本地补丁。
保留原始 MIT 许可证 `LICENSE`。

## 修改的文件与原因

- `plugin.gd`：关闭分屏时，在移除容器后调用 `queue_free()`。释放容器及其 CodeEdit，避免遗留离树节点。
- `split/split_code_edit.gd`：只读分屏使用独立的逐行高亮快照。两边各自拥有高亮器，避免分屏释放后原编辑器访问失效对象。

## 升级时保留补丁

1. 对照固定源码、本地修改和新上游版本。
2. 逐项确认上游是否修复上述问题。
3. 上游已修复时，验证后采用上游实现。
4. 尚未修复且仍可复现时，保留对应处理。
5. 核对分屏释放和两边的高亮器，再更新本文件。

验证在外部项目中覆盖反复开关分屏、关闭后原编辑器的高亮更新，以及编辑器退出。保留许可证，不直接用上游目录覆盖仍需保留的修改。
