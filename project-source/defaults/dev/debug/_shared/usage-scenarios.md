# 调试台使用场景

本页按"你想做的事"列出调试台的操作路径，用于设计、按界面任务试用和验收。每个界面任务写：目标、操作步骤、应看到的反馈、试用要点。界面改动后，按本页逐条走一遍；任何一步需要你懂系统内部（目录、文件、引擎报错）才能完成，都算缺陷。

## 试用通用标准

- **一眼找到入口**：不看说明，3 秒内能找到要点的按钮；图标按钮悬停有"动作 + 后果"的提示。
- **一个动作一个结果**：点一次就完成这件事，不出现"先去做另一件你做不了的事"。
- **反馈说人话**：成功说做成了什么，失败说做不到什么、为什么、怎么办；不出现引擎错误名、`res://` 路径、内部术语。
- **有风险先确认**：会改游戏文件、会删除东西的操作，确认框写清楚会改什么。
- **能反悔**：任何修改都能单项还原或整体回到游戏原值。
- **状态看得见**：当前在用哪套值、有没有未保存、是否正在播放并锁定参数，不用猜。

## 界面任务

### 1. 打开调试台

- **目标**：一边玩游戏一边调参数。
- **步骤**：运行启动命令；出现游戏窗口和调试窗口两个窗口。
- **术语**："游戏原值"指游戏文件里保存的值，也就是不开调试台时游戏使用的值。全界面只用这一个词。
- **应看到**：调试窗口"调参"页，播放条的调试对象下拉显示中文名，左侧插槽列表按类别分组（global 的插槽在“全局”组），右侧提示选择一个插槽。
- **试用要点**：两个窗口互不遮挡；按 F1（任一窗口）能隐藏或显示调试窗口。

### 2. 边玩边调一个参数

- **目标**：把一个特效调大一点。
- **步骤**：左侧点这个特效的插槽 → 拖"尺寸"滑块或在数值框输入 → 回游戏触发这个特效。
- **应看到**：下一次触发就用新值；"尺寸"行左侧出现琥珀竖条和行尾还原按钮；左侧该插槽旁出现琥珀点；底部显示"1 个插槽未保存"。
- **试用要点**：不需要点任何"应用"按钮；改动标记一眼可见。

### 3. 和原来比较

- **目标**：判断刚调的版本是否比原来好。
- **步骤**：按 ` 键，或点对比条上的"当前改动 / 游戏原值"两侧开关，来回切换。
- **应看到**：在"当前改动"和"游戏原值"之间切换，正在显示哪一侧一眼可见；显示"N 处不同"。播放固定局面时，切换在下一遍开头生效并有提示。
- **试用要点**：不需要事先保存任何东西；没有改动时按 ` 只提示"还没有改动可对比"。

### 4. 换一个实现并试一下

- **目标**：把一个音效换成另一个候选，或把一个特效换成另一种实现。
- **步骤**：选插槽 → 在"实现"里点另一个候选 → 点"试播"（特效）或在游戏里触发一次（音效）。
- **应看到**：选中的候选高亮；"游戏在用"标记仍留在当前游戏采用的那个上；参数区只显示该候选自己的参数。
- **试用要点**：分清"我正在试的"和"游戏在用的"。

### 5. 满意了，采纳到游戏

- **目标**：让游戏以后默认就用现在这套。
- **步骤**：点检查器右下"采纳到游戏"→ 确认。
- **应看到**：确认框写清会做什么（例如"把 风铃 · chime 移入游戏，并把按钮音效改为它"）及会修改的游戏文件；完成后提示"已采纳：……"；音效、图片类候选当场生效，"游戏在用"标记移到新候选；特效场景、脚本类候选标"下次启动生效"，下次启动调试入口时自动移入。未保存提示消失，插槽回到"游戏原值"（预设下拉显示"游戏原值"）。
- **试用要点**：一次确认就完成，不要求你先做别的；之后由 Agent 收尾提交，不需要你操作。

### 6. 改坏了，想反悔

- **目标**：撤回改动。
- **步骤**：单个参数点行尾还原；整个插槽点"撤销改动"；想回到游戏原值，在预设下拉选"游戏原值"。
- **应看到**：单项还原和“撤销改动”立即恢复，改动标记消失。选“游戏原值”时，如果这个插槽有未保存的改动，先问“保存 / 不保存载入 / 取消”：“不保存载入”直接回到游戏原值，“保存”先把改动存成预设再载入，“取消”什么都不改；没有未保存的改动时直接回到游戏原值。
- **试用要点**：三种粒度的反悔都找得到，且不会误删已保存的预设。

### 7. 存成预设，以后再用

- **目标**：保存一个插槽当前的调法，以后还能调出来。
- **步骤**：检查器"参数"标题右侧点保存（或在预设下拉选"另存为新预设"并起名）。
- **应看到**：预设下拉出现新名字；未保存提示消失。以后在下拉中选它即可加载。
- **试用要点**：能区分"保存预设"（只存草稿，游戏不变）和"采纳到游戏"（改游戏）。另存时命名框预填一个不重名的新名字；输入已有的名字，先问"覆盖 / 换个名字 / 取消"，不会悄悄覆盖。

### 8. 存一整套搭配并比较

- **目标**：比较两套搭配，例如"清脆音效 + 圆环特效"和"低沉音效 + 火花特效"。
- **步骤**：调好第一套 → 保存为组合；调好第二套 → 另存为组合；把对比对象从"游戏原值"改成第一套组合；按 ` 切换。有未保存的插槽时，起好组合名后确认“一并保存”。
- **应看到**：两套搭配原位来回切换，显示不同处数。
- **试用要点**：组合与插槽预设的关系清楚：组合 = 每个插槽各选一个预设。“一并保存”的确认框逐个列出插槽的改动存进哪个预设；预设被别的组合使用时写明改存的新名字。

### 9. 用固定局面重复看

- **目标**：反复看同一段游戏过程，慢放细节。
- **步骤**：播放条选一个固定局面 → 点播放；需要时暂停、继续、回到开头；调倍速、循环次数。
- **应看到**：播放主按钮依次变成暂停、继续；右侧显示"第 n/N 遍"和"已锁定参数"；播放中参数区变灰，悬停被锁定的按钮、下拉框说明要先点“回到开头”。
- **试用要点**：为什么不能改参数一看便知；回到开头能结束播放并恢复可编辑。

### 10. 在很多插槽里找到要调的

- **目标**：插槽上百个时快速定位。
- **步骤**：搜索框输入名称、编号或参数名；切换"全部 / 已修改 / 钉选"；点钉选图标把常用插槽固定在前面。
- **应看到**：列表即时过滤，数字显示数量；没有符合条件的插槽时，列表写出当前筛选和搜索词，以及怎样看到所有插槽。
- **试用要点**：筛选状态清楚，不会以为插槽丢了。

### 11. 看音效分析，把结果写回参数

- **目标**：了解候选音效的响度和音高，并用插槽提供的分析动作把结果写进参数。
- **步骤**：选一个音效插槽 → 选一个音效候选 → 检查器中部"分析"区查看数值 → 如果"分析"标题右侧有动作按钮，点它写入参数 → 播放固定局面听效果。
- **应看到**：分析区首次显示"分析中…"后出现数值；分析动作在数据不可靠时不可点并说明原因；插槽提供的说明显示在数值下方；写入的参数按插槽的写法显示（例如基础音高显示音名）。
- **试用要点**：选"未设置"时分析区不出现，不显示空白或报错。

### 12. 看画面的色觉模拟

- **目标**：检查当前画面对色觉障碍玩家是否仍可分辨。
- **步骤**：切到"分析"页 → 点"截图分析"。
- **应看到**：正常、灰度、红色盲、绿色盲四格并排；可打开原图。
- **试用要点**：在"调参"页时这块不占地方；分析期间游戏不卡。

### 13. 结束调试

- **目标**：关掉调试台。
- **步骤**：关闭游戏窗口。
- **应看到**：如果有未保存的改动（包括切换调试对象前在别的对象里留下的改动），提示"有 N 个插槽的改动还没保存，关闭后会丢失"，可选保存（存成预设，游戏文件不变）、不保存直接关闭、取消。已存成预设但未采纳的改动不会丢，不计入。
- **试用要点**：不会因为误关丢掉调了半天的值。

## 容易误解、需要重点核对的概念

| 概念 | 用户可能的误解 | 界面上必须说清的 |
| --- | --- | --- |
| 改参数 | 以为已经保存 | 只在本次运行有效，未保存有提示 |
| 保存预设 / 组合 | 以为游戏也变了 | 只存草稿，游戏不变 |
| 采纳到游戏 | 以为只是保存 | 会改游戏文件，成为游戏默认值 |
| 游戏在用 / 正在试 | 分不清 | 两种标记长得不同 |
| 对比 | 以为要先准备两组 | 默认和游戏原值比，零准备 |
