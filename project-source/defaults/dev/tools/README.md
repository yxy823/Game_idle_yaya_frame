# 项目脚本

本目录保存项目自己的常用命令脚本，例如导出打包、批量重新生成内容表。`dev/` 在正式导出时整体排除，这里的脚本不会进入游戏包。框架随项目提供的检查与测试工具在 [`yaya/tools/`](../../yaya/tools/README.md)，不放在这里。

何时保存、保存前怎样征求用户同意、保存后要做什么，见[保存常用脚本](../../yaya/methodology/09-records-reports-and-handoff.md#保存常用脚本)。
