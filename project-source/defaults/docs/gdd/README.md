# 游戏设计文档目录

本目录保存持续维护的 GDD 设计正文：游戏定位、核心循环、系统规则、数值、体验与反馈目标、内容与版本范围。`README.md` 是固定的总览入口。

本页只说明目录用途，不能代替 GDD。可以导入已有设计，也可以用 `design-gdd` 从游戏想法开始讨论并编写初稿；数值建模与调参用 `design-balance`。
