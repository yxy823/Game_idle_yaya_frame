# 界面规格目录

这里保存具体界面的布局、交互呈现、状态差异、显示条件和界面专用资源规格。设计界面时按需创建 `<interface>-design.md`，例如 `inventory-design.md`；示例不代表已有界面。

界面在实际交互位置引用相关[游戏表现](../presentation/README.md)，并在末尾维护“关联游戏表现”导航。普通控件状态可就地描述；跨界面共用的表现引用同一份正文，保留各界面的触发与使用信息。

当前尚无界面规格。新增、改名或移除规格时，在本页维护“文档链接、界面用途、关联 Product”的简短导航；具体要求保留在各规格正文。职责见 [专业工作约定](../../methodology/11-specialist-workflows.md)。
