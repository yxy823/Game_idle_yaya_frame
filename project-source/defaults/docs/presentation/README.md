# 游戏表现目录

这里导航到游戏中一次完整表现的设计，例如物品入包或角色死亡；这些名称仅作说明，不代表项目已有需求。使用 `design-game-presentation` 按“触发时刻与玩家感知的结果”确定 `<scope>.md`：商店购买和奖励领取若都表达同一次物品入包，共用 `item-added.md`，分别说明来源上下文；奖励揭晓等具有不同起止和结果的过程单独成文，结束时引用物品入包正文。文档记录过程、组成部分、候选、资源、采用组合、实现与消费位置及既有验收入口。

同一个表现被多个界面使用时，组件正文仍留在该表现内。第二份独立表现使用相同组件要求时，按下方文档约定将共用正文迁入 `components/<component-key>.md`；本页同时导航到共享组件及其消费表现，不另建组件索引。

“表现层”还包括界面、共享视觉与声音规范等内容，本目录专门承载一次具体表现。触发它的游戏规则引用 GDD，实际状态所有者与连接关系引用架构或任务设计；整体关系见[游戏职责与项目组织](../game-organization.md)。

当前尚无游戏表现正文。新增、改名、拆分或移除文档时维护下表；具体要求、准备状态和采用情况保留在对应正文，验收结果保留在所链接的既有报告或完成记录中。职责见[游戏表现文档约定](../../methodology/11-specialist-workflows.md#game-presentation-documents)。
