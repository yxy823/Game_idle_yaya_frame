# 本地化规范

本文维护游戏的目标语言与回退、文本与代码分离、字体覆盖、语言区域格式、语气与用词和术语译名；完整译文保存在运行资源中。项目术语的含义引用[项目术语](../terminology.md)，本页只规定目标语言怎样表达这些概念。项目文档语言不代表游戏语言。

## 目标语言与覆盖范围

游戏只提供简体中文（`zh_CN`），简体中文同时是源语言；没有语言切换和回退语言。范围是游戏内全部玩家可见文字。这是框架的默认做法，见[玩家可见文本](../../yaya/methodology/11-specialist-workflows.md#玩家可见文本)；需要其他语言时先改本节，再做实现。

## 文本与代码分离

玩家可见文字从第一个包含玩家可见文字的 Feature 起与代码分开：通过稳定的翻译键取得，源语言原文放在翻译资源中，含数值或名称的句子用整句加命名占位符，不在脚本里拼接。翻译资源格式和键的命名按 `content-localization` 的约定。

## 字体覆盖

游戏字体必须覆盖翻译资源中实际出现的全部字符、数字和标点。字体的选择属于[美术圣经](../art/art-bible.md)；这里只写各语言的覆盖要求和缺字时的回退字体。

## 语言区域格式

本节写各语言在千位分隔符、小数点、缩写单位译法、日期和时间上的差异。数字怎样缩写、取整和带什么单位属于游戏表现，写在 GDD 的 `presentation.md`。

## 语气与用词

玩家可见文本的语气、对玩家的称呼和用词风格，源语言和各目标语言分别说明；只有源语言时也写在这里。写法与归属见[玩家可见文本](../../yaya/methodology/11-specialist-workflows.md#玩家可见文本)。

## 术语译名

这里是已确认术语译名的唯一规格，由 `design-localization-spec` 维护。条目链接项目术语中的概念，说明目标语言、已采纳译名和适用语境；候选标为待定，完整句子与对话不复制到本页。实现与语言审核据此核对运行资源，具体约定见[本地化术语译名](../../yaya/methodology/11-specialist-workflows.md#本地化术语译名)。
