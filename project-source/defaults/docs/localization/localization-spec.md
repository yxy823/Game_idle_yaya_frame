# 本地化规范

本文维护游戏目标语言、翻译表达、变量与复数、回退和格式约定；完整译文保存在运行资源中。项目术语的含义引用[项目术语](../terminology.md)，本页只规定目标语言怎样表达这些概念。项目文档语言不代表游戏语言。

玩家可见文本的语气、对玩家的称呼和用词风格，源语言和各目标语言分别说明；只有源语言时也写在这里。写法与归属见[玩家可见文本](../../yaya/methodology/11-specialist-workflows.md#玩家可见文本)。

## 术语译名

这里是已确认术语译名的唯一规格，由 `design-localization-spec` 维护。条目链接项目术语中的概念，说明目标语言、已采纳译名和适用语境；候选标为待定，完整句子与对话不复制到本页。实现与语言审核据此核对运行资源，具体约定见[本地化术语译名](../../yaya/methodology/11-specialist-workflows.md#本地化术语译名)。
