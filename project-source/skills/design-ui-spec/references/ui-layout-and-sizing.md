# 界面布局与尺寸

界面布局、间距和尺寸的默认做法。`design-ui-spec` 写界面规格和摆草稿界面时使用，`review-art` 和 `review-ux` 审核时引用。UI 规格或 Art Bible 已采用不同的决定时，以已采用的决定为准。具体像素、间距和字号在调试台决定，见[草稿界面](../SKILL.md#草稿界面)；节点上的实现规则按 `yaya/agent-rules/20-scenes/ui-and-scripts.md` 的“布局”执行。

## 分组与层级

- **L1 眯眼测试**：模糊细节后，仍能按顺序认出主元素、次元素和主要分组。
- **L2 先靠距离分组**：组内紧、组间松，距离不够表达分组时再加容器。标题上方的间距至少是下方的两倍，让标题贴近它下面的内容。
- **L6 密度**：密度按使用频率和决策复杂度定。营销页的大留白不搬进游戏 HUD。
- **L7 卡片对齐**：并排的卡片里，同类元素在同一水平线：标题、价格、按钮对齐，按钮固定在卡片底部。

## 档位

- **L3 间距刻度**：间距用 4 的倍数（4、8、12、16、24、32），不写一次性数值。像素风用素材的原生像素单位。只有内容真正等价时，才重复同一种版式。
- **L4 尺寸四档**：控件尺寸分四档：微型（角标、关闭按钮）、小（紧凑工具栏、标签页）、标准（大多数按钮和列表项）、大（主操作）。大档全屏只有一个。鼠标可点击区域不小于约 24px。
- **L5 同心圆角**：嵌套元素的圆角满足：外层圆角 ≈ 内层圆角 + 内边距。胶囊形只用于进度条、筛选标签和状态徽章，面板不用。
- **L8 光学校正**：图标与文字并排、按钮内的文字，按渲染结果做 1–2px 的位置校正。

## 窗口与可用空间

- **L9 按自己的可用空间布局**：控件的布局按它自己拿到的宽高决定，不按窗口宽度判断。例如打开侧栏后主区域变窄，主区域里的卡片按变窄后的宽度排列。用 Container、尺寸标志和最小尺寸实现。
- **L10 比例为主、尺寸兜底**：布局以比例为主，用最小和最大尺寸兜底。超宽窗口里内容区限宽居中，不把列表拉成一整行细条。检查最小窗口以及 16:9、16:10、21:9：没有水平溢出，没有中文单字竖排，图标没有被非等比拉伸。
- **L11 安全网档位**：设一个最窄的档位，空间极窄时压缩内边距、按钮只留图标，保证不溢出。
