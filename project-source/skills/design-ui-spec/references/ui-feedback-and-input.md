# 界面反馈与输入

控件状态、操作反馈、输入容错和文本呈现的默认做法。`design-ui-spec` 写界面规格时使用，`review-ux` 审核时引用。UI 规格或 GDD 已采用不同的决定时，以已采用的决定为准。一次完整的游戏表现（例如领取奖励）属于 `design-game-presentation`。

## 状态与反馈

- **F1 控件状态齐全**：每个可交互控件都配置默认、悬停、按下、焦点、禁用状态，需要时加上加载和错误。同类按钮在全游戏外观一致。
- **F2 空状态**：空状态说明这里会出现什么、为什么有用、怎样开始，并给出下一步操作。
- **F3 需要时间的操作**：需要时间的操作至少有等待、进行中、成功或失败三种状态，每种状态都有可见的界面变化。失败时给出下一步，例如重试或返回。
- **F16 两种反馈通道**：每种关键状态至少有两种反馈通道，例如画面加声音；关掉声音后，关键信息仍能从画面上看到。

## 防误操作

- **F4 防连点**：任一按钮以每秒 20 次的速度连点，不出现重复扣费、重复弹窗、提示堆叠或状态错乱。关键按钮在处理期间禁用。
- **F5 破坏性操作**：不可逆的操作（例如删除存档）弹出确认：默认焦点不在危险项上；文案写明对象和“不可恢复”；批量操作显示真实数量。可逆的操作不弹确认，改用撤销。已采用的普通游戏内货币购买不算破坏性操作，按 `review-ux` 的必须项 M4 判断。
- **F6 点击与拖拽**：用约 4px 的移动死区区分点击和拖拽：位移超过死区才进入拖拽。长按要同时满足按住时间达标和位移未超过死区。
- **F7 拖拽四件套**：拖拽时源对象降低透明度；原位留下占位；按目标的中线判断插在前面还是后面；落点显示导轨。按 Esc 或拖到非法区域时取消，对象回到原位；放在非法落点时给出拒绝反馈，不静默不动。
- **F8 缩放**：缩放以鼠标指针为不动点：指针下的细节在缩放中保持不动。到达上下限时有阻尼，不硬停。

## 文字

- **F9 动作与文案**：按钮写明动作的结果，同一个动作在全流程同名，例如按钮写“升级”，提示写“已升级”。错误提示说清问题和恢复办法，不道歉。标准动作用玩家熟悉的标准文案。
- **F10 草稿的样例数值**：草稿界面的样例数值用真实量级，例如 1.27M，不用 100、50% 这样的整数，否则看不出真实数据下的宽度。
- **F11 溢出策略**：每处文本显式选一种溢出策略：换行、省略号、缩小字号（写明下限）或滚动。用“最长内容 × 最窄容器”检查，中文不出现单字竖排。
- **F14 逐字出现**：逐字出现的文本可以跳过；跳过的这一下不触发下一步。
- **F15 文本输入**：输入法正在选候选词时，回车只确认候选词，不提交表单。按 Esc 取消编辑并还原原值。

## 列表

- **F12 自动滚动不抢视口**：自动滚动的列表（日志、消息）里，玩家一向上滚动就停止自动跟随，新内容不把视口拽回底部；玩家回到底部后才恢复跟随。玩家离底部较远时，显示“跳到最新”。
- **F13 滚动边缘渐隐**：滚动边缘的渐隐用非线性曲线；已经滚到头的一侧不渐隐；渐隐区不挡点击。
