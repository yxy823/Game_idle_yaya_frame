# 界面字体与数字

界面字体、字号和数字显示的默认做法。`design-art-direction` 定 Art Bible 的字体时使用，`design-ui-spec` 写界面规格、`review-art` 审核时引用。Art Bible 或 UI 规格已采用不同的决定时，以已采用的决定为准。字体文件的导入、授权和字形回退按 `yaya/agent-rules/60-assets/font-assets.md` 执行。

## 字体与字号

- **Y1 字号少而拉开**：每屏 2–3 个字号承担主要工作，最多 5 个。相邻两档看起来差不多时合并成一档。每屏只有一个主导字号。
- **Y2 层级的手段**：层级同时用字号、字重、间距和色调建立，不全部加粗。细分层级用 500 或 600 的中等字重。
- **Y3 字体数量**：字体最多两种，一种够用时只用一种；用第二种时，它必须有独有的用途。标签、按钮和数值不用展示字体。
- **Y4 不靠字体装饰**：不用等宽字体表现“技术感”；不用全大写加大字距的小标签。
- **Y7 行宽**：描述类文本限制行宽。Tooltip 定宽，不随内容撑到屏幕边缘；段落约 60–80 个中文字符一行。

## 数字

- **Y5 跳动的数字用等宽数字**：资源数、价格、计时器这类会变的数字，用等宽数字，避免数值变化时左右抖动。做法是开启字体的 `tnum` 特性（`FontVariation` 的 OpenType 特性），或者选数字等宽的字体，或者用固定宽度的槽位加右对齐。不每帧测量文本宽度再补偿位置。
- **Y6 大数与缩写**：用百万、十亿以上的数值、0 值、空列表和长文本检查溢出和截断。千分位和单位缩写（例如 K、M、B）全游戏统一一套写法。
