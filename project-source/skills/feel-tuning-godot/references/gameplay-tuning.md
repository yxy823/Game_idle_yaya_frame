# 调操作手感与普通参数

适用于移动、跳跃、攻击响应这类操作手感，以及没有使用表现反馈组件的特效和动画。这类参数没有现成的工作台，按下面的方式配合。

## 先让参数可调

- 参数集中放在一个资源（`.tres`）或节点的导出变量中，不散落在代码的常量里。新增参数资源属于实现修改，在当前授权内完成，并遵循 `yaya/agent-rules/` 中资源与 GDScript 的规则。
- 不为调参新增运行时调试面板或热键，除非用户要求，或者对比确实离不开实时切换。新增时只放在开发构建中，并在导出时排除。

## 和用户配合的一轮

两种做法，按参数是否需要边玩边改来选：

- **改值后重新运行**：Agent 修改资源中的值（A 的值写在 notes 里备查），用户重新运行场景感受，再告诉 Agent 选哪个。适合大多数情况。
- **运行中直接改**：用户从编辑器运行游戏，在“远程”场景树里选中节点，直接在检查器中修改属性，立刻看到效果。Agent 事先告诉用户改哪个节点的哪个属性、试哪几个值。运行中的修改不会保存，用户选定后由 Agent 把值写回资源。

连续触发或特定关卡才出现的问题，告诉用户在什么情况下比较。

## 结束时

把选定的值写进参数资源，删除只为对比加的临时代码或临时值。Agent 核对资源中的值和场景实际读取的一致，相关自动测试仍然通过。
