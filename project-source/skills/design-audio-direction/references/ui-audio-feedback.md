# 界面音效与反馈声音

界面音效和反馈声音的默认做法。`design-audio-direction` 定 Sound Bible 的反馈优先级、重复疲劳和过渡时使用，`review-audio` 审核时引用。Sound Bible 或 GDD 已采用不同的决定时，以已采用的决定为准。文中的音量是项目决定音量时的初始值，不是每个项目都要定的规格；混音实现属于实现任务。

## 音量与总线

- **A1 界面音效更轻**：界面音效默认明显低于游戏音效，例如界面音效约 40–50%，游戏音效约 70–80%。主音量、音乐、音效、界面音效和语音各有一个音量滑条。
- **A2 总线早分**：音频总线在项目初期分好：音乐、世界音效、界面音效、语音。界面音效单独一条，方便在剧情等场景整体压低，不影响打击反馈。

## 防爆音

- **A3 不硬切**：音效的开始和截断加 5–15ms 的增益斜坡。音量变化走插值，不直接赋值。淡出用指数型曲线，不用线性，因为线性淡出听起来像突然消失。暂停时统一挂起总线，不逐个关掉播放器。

## 重复与并发

- **A4 微随机与并发上限**：重复播放的同类音效加音高和音量的微随机（约 ±5–10%），连续播放 20 次不像复印机。同一帧的并发数设上限，总线上加限制器，避免叠加削波。
- **A5 合成还是样本**：计数、悬停、拾取、连击递升这类音效，适合程序化合成，或用少量样本变调；连击音可以按连击数提高音高。打击感、语音和音乐用样本。
