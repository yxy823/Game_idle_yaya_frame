# Art review

Apply `methodology/12-independent-review.md`. Compare approved art direction and local specifications with the actual displayed result, including context and target scale, not only isolated full-resolution source assets.

Inspect silhouette and recognizability, visual hierarchy, palette/contrast, perspective, material/detail consistency, animation language and state distinction where applicable. Check whether cropping, transparent margins and scaling change the intended subject size. Use representative crowded and contrasting backgrounds when they matter to the requirement.

Separate measurable contract violations from subjective alternatives. An unresolved style proposal cannot establish a defect. Missing target-view evidence leaves in-context fit unverified; text descriptions or file presence do not prove it. Technical provenance/import concerns may use `review-assets` in the same independent instance.

Return evidence-linked findings and the reviewed display conditions. Do not alter artwork, choose a new style or treat this review as the user's visual acceptance.
