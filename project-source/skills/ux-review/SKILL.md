# UX review

Apply `methodology/12-independent-review.md`. Read the relevant user goal,
Product behavior and UI specification, then inspect actual screen/interaction
evidence for the requested flow and display/input conditions.

Trace whether actions are discoverable, state and feedback are understandable,
navigation/focus is predictable, mistakes are recoverable and the flow supports
the goal. Include relevant empty, loading, disabled, error, dense/long-text and
repeated-entry states. Examine readable contrast, target size, input method and
non-color cues where the task requires them; do not invent a certification standard.

Distinguish demonstrated interaction problems, requirement violations and design
suggestions. Static mockups cannot establish keyboard/controller operation or
timing, and screenshots alone cannot establish end-to-end usability. If actual
interaction evidence is unavailable, limit the conclusion accordingly.

Report concrete user action, observed obstacle, consequence and evidence location.
Do not redesign the screen, edit its specification or substitute for human
experience acceptance. Gameplay motivation/retention playtesting is outside scope.
