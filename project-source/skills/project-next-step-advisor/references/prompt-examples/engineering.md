来源：Godot 项目开发 → 修复与改进 → Feature 交付前发现 Bug

```text

- 完成后：保留实际失败并取得修复后的必要自动与人工复验；检查最终差异，说明关键文件、修复理由及具体剩余风险，再返回原 Feature 的完成检查。
```
