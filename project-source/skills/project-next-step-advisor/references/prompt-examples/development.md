## 继续中断的当前任务

来源：Godot 项目开发 → 日常开发 → 继续中断的当前任务

```text
请继续当前未完成的任务。
任务或 Feature：${1:标识；不确定时说明最近在做什么}
新增信息：${2:本次补充要求、反馈或已有决定；无则填无}

读取项目 AGENTS.md、当前 Progress、相关任务记录和 Git 差异，只补读必要历史。先确认实际停点、修改归属、仍有效的授权以及尚未完成的工作。

沿用当前任务对应的 Skill 继续，不重新生成台账、不重复已经完成且仍有效的工作，也不把“继续”推定为缺失的人工验收。存在关键冲突或未知修改时说明具体问题。

从真实停点继续完成当前已授权范围内的工作，包括适用的实现、验证、记录与本地交付；不因完成一个局部步骤或 Skill 返回就提前结束。检查证据是否仍覆盖最终修改，旧报告不能冒充新验证。仅在授权范围完成、用户要求暂停、必要前置受阻或缺少实质决定时停止，并说明已完成范围和具体缺口。
```
