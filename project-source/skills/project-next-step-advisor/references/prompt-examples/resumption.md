## Feature 还没做完，准备换一个对话继续

来源：Godot 项目开发 → 项目恢复与交接 → Feature 还没做完，准备换一个对话继续

```text
## 目标

请整理必要进度并生成一段可直接复制到新对话的续接指令。

## 背景与入口条件

当前对话需要为同一目录中的原任务准备可靠交接。

## 范围

准备同一目录原任务的新对话交接，只改必要进度文档并暂停原实施。

## 输入与事实来源

${1:当前 Feature、原目标、已决定事项与换对话意图}

核对实际目录、Git、任务、目标、决定、有效授权、原件及真实剩余工作。

## 决策边界与授权

只授权必要记录和交接；不自动创建对话、发送任务或从交接补造批准。

## 约束

遵循 methodology/09-artifact-lifecycle.md；不为清空现场提交或回滚，不建 Handoff 文件，不伪造验收。

## 输出与交付

输出完整可复制续接代码块，引用必要停点记录。 生成的指令使用目标、范围、输入与事实来源、决策边界与授权、约束、输出与交付、验证要求、完成条件 8 个固定字段，以 Markdown 二级标题明确标识，填入已核实的具体内容；适用的附加字段按场景补充。

## 验证要求

核对交接与当前文件和运行状态一致，要求接收方先核对同一目录再继续。

## 完成条件

完整交接文本和必要记录已准备，原任务暂停在真实位置。

## 停止与异常处理

输出交接后暂停原实施；旧实施授权不覆盖本次暂停，用户明确续接后再恢复。

## 后续事项与未完成项记录

在现有 Progress 和必要 notes 保留真实剩余工作、有效授权、决定、原件和恢复第一步，交接文本引用这些记录。
```
