# Yaya 框架文档编写与整理

把 Yaya 框架中已确认的事实和操作要求，整理成容易查找、理解和执行的说明。

## 适用范围

**适用于**：框架入口与各级 README、Godot 项目手册、场景速查手册、框架维护文档、`tools/` 与测试夹具的用法说明、审核报告，以及分发源中的说明文字。Godot 项目手册虽然介绍游戏开发，也由本 Skill 负责。

**不适用于**：

- 实际生成项目中的 GDD、Product、Feature 等文档，由该项目自己的写作 Skill 负责。
- 只是阅读文档。

**编辑 AGENTS、Skill 或任务提示词时**：本 Skill 只处理已确认内容的表达。规则行为的维护和自查按[规则与提示词文件](../../../framework/maintenance/design-guidelines/instruction-files.md)，具体职责和流程由所属规范决定。

## 交付什么

- **只讨论方案时**：交付建议。
- **获准修改时**：完成相应文档的修改和作者自查。

两种情况都不改变被说明对象的行为或验收标准；作者自查也不能称为正式审核。

## 从哪里开始

先读[框架写作指南](references/writing-guide.md)，确定本次范围、表达方式和检查边界。普通的单页润色读这一份就够。需要时再读：

- [框架文档结构](references/document-structure.md)：整理整套手册或维护材料，处理页面分工、命名、术语或正文去重时。
- [流程与场景文档](references/procedure-writing.md)：编写操作步骤、维护流程或场景页时。

## 资源与依据

- **独立维护**：本包的参考资料通过内部相对路径读取，不依赖 Godot 版写作 Skill；唯一的例外是措辞检查的说明，它只维护在 Godot 版写作指南的「措辞检查」一节，本包链接它。
- **事实来源**：框架的实际目录、术语、提示词映射、构建与验证要求，来自根 `AGENTS.md` 及其链接的入口；按本次任务读取，本包不复制工具参数，也不另立执行流程。
- **不分发**：本 Skill 只供框架维护使用，不随空白游戏项目分发，不需要安装、同步或配套脚本。
